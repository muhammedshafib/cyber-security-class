## Subnet Calculation
### 192.168.1.0/24
calculate about this ip address

1) Network :- 192.168.1.0
2) CIDR notation :- /24
                 = 255.255.255.0
3) Network = 24 bit
4) host = (total bit-network=host net)
        =32-24=8 bit
5) Total address = 2^8 = 256
6) used host = 256-2=254

Network = 192.168.1.0

broadcast = 192.168.1.255

used address = 192.168.1.1 - 192.168.1.254
