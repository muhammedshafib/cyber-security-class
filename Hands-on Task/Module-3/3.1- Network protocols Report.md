# Identify Network Protocols Using Wireshark

### Objective:
To capture network packets and identify different
network protocols using Wireshark.

### Tools Required:
1. Computer
2. Wireshark
3. Network connection
4. Browser
5. Command Prompt/Terminal

### Procedure:
1. Open Wireshark.
2. Select the active network interface.
3. Start packet capture.
4. Generate normal network traffic.
5. Apply protocol filters.
6. Inspect packet details.
7. Identify protocols.
8. Record observations.
9. Stop the capture.
10. Save the capture file.

### Protocols Identified:
ARP
DNS
ICMP
TCP
UDP
TLS/HTTPS
DHCP

### Result:
Successfully captured network traffic and identified
different network protocols using Wireshark.
