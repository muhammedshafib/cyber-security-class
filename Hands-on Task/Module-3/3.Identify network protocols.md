# 1. What is a Network Protocol?

### English

A **network protocol** is a set of rules that allows devices to communicate over a network.

Examples:

```text
HTTP
HTTPS
DNS
DHCP
ARP
TCP
UDP
ICMP
SSH
FTP
```

Each protocol has a specific purpose.

# 11. Identify ARP

In the Wireshark display filter:

```text
arp
```

Press Enter.

You should see ARP packets if ARP traffic was captured.

Example:

```text
Protocol: ARP
```

### What is ARP?

**ARP = Address Resolution Protocol**

It maps an IPv4 address to a MAC address on a local network.

Example concept:

```text
Who has 192.168.1.1?

192.168.1.1 is at
AA:BB:CC:DD:EE:FF
```

### Malayalam

ARP എന്നത്:

**IP address → MAC address**

mapping കണ്ടെത്താൻ local network-ൽ ഉപയോഗിക്കുന്ന protocol ആണ്.

# 14. Identify TCP

Use:

```text
tcp
```

filter.

You will see TCP packets.

TCP is a **connection-oriented transport protocol**.

One important process is the TCP three-way handshake:

```text
Client                  Server
  |                       |
  |-------- SYN --------->|
  |<------ SYN/ACK -------|
  |-------- ACK --------->|
  |                       |
       Connection
       established
```

### Malayalam

TCP connection establish ചെയ്യുമ്പോൾ സാധാരണയായി three-way handshake നടക്കും:

```text
SYN
 ↓
SYN-ACK
 ↓
ACK
```

Wireshark-ൽ packet `Info` column-ൽ ഇത് കാണാൻ കഴിയും.

# 15. Identify UDP

Filter:

```text
udp
```

UDP is another transport-layer protocol.

Compared with TCP:

```text
TCP → Connection-oriented
UDP → Connectionless
```

DNS commonly uses UDP for ordinary queries, typically on port 53, although DNS can also use TCP and other transport mechanisms in certain situations.

### Malayalam

UDP ഒരു **connectionless transport protocol** ആണ്.

Common example:

```text
DNS
```

DNS traffic പല സാഹചര്യങ്ങളിലും UDP port 53 ഉപയോഗിക്കും.

# 21. Most Important Protocol Table

| Protocol | Full Form                           | Layer                | Common Port |
| -------- | ----------------------------------- | -------------------- | ----------: |
| ARP      | Address Resolution Protocol         | Link                 |           — |
| ICMP     | Internet Control Message Protocol   | Network              |           — |
| IP       | Internet Protocol                   | Network              |           — |
| TCP      | Transmission Control Protocol       | Transport            |           — |
| UDP      | User Datagram Protocol              | Transport            |           — |
| DNS      | Domain Name System                  | Application          |          53 |
| DHCP     | Dynamic Host Configuration Protocol | Application          |       67/68 |
| HTTP     | Hypertext Transfer Protocol         | Application          |          80 |
| HTTPS    | HTTP over TLS                       | Application/Security |         443 |
| SSH      | Secure Shell                        | Application          |          22 |
| FTP      | File Transfer Protocol              | Application          |          21 |

Port numbers are useful clues, but **identify the protocol from the packet contents/decoder too**, not only from the port number.

A set of rules used for network communication.

**2. What is Wireshark?**

Maps an IPv4 address to a MAC address on a local network.

**4. What does DNS do?**
Resolves domain names to IP addresses.

**7. What does UDP do?**
Provides connectionless transport.

Provides cryptographic protection for protocols such as HTTPS.

Filtering packets in Wireshark to focus on specific traffic.

Examining packet information to understand network communication.
