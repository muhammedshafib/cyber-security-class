## Complete Step-by-Step Explanation — English + Malayalam

Subnetting is one of the **most important practical skills in networking and cybersecurity**. It is used to divide a large IP network into smaller networks called **subnets**.

---

# 1. What is Subnetting?

### English

**Subnetting** is the process of dividing one large IP network into multiple smaller logical networks.

For example:

```text
192.168.1.0/24
```

This network contains **256 total IP addresses**.

Instead of using all 256 addresses for one network, we can divide it into smaller networks:

```text
192.168.1.0/26
192.168.1.64/26
192.168.1.128/26
192.168.1.192/26
```

Now we have **4 smaller subnets**.

### Malayalam

**Subnetting** എന്നത് ഒരു വലിയ IP network-നെ ചെറിയ ചെറിയ network-കളായി വിഭജിക്കുന്ന process ആണ്.

ഉദാഹരണം:

```text
192.168.1.0/24
```

ഇതിൽ ആകെ **256 IP addresses** ഉണ്ട്.

ഇത് ചെറിയ network-കളായി divide ചെയ്യാം:

```text
192.168.1.0/26
192.168.1.64/26
192.168.1.128/26
192.168.1.192/26
```

ഇങ്ങനെ ഒരു വലിയ network-നെ 4 ചെറിയ subnet-കളാക്കി മാറ്റാം.

IPv4 address:

```text

```

IPv4-ൽ **32 bits** ഉണ്ട്.

4 octets:



# 7. CIDR Notation

You will commonly see:

```text
192.168.1.10/24
```

Here:

```text
/24
```

means the first **24 bits are network bits**.

IPv4 has 32 bits.

Therefore:

```text
Network bits = 24
Host bits = 32 - 24
           = 8
```

### Malayalam

`/24` എന്നത് ആദ്യത്തെ 24 bits network portion ആണെന്ന് അർത്ഥമാക്കുന്നു.

```text
Total bits = 32
Network bits = 24
Host bits = 8
```

---

# 8. Host Calculation Formula

The basic formula is:

```text
Number of addresses = 2^host bits
```

For traditional IPv4 subnetting:

```text
Usable hosts = 2^host bits - 2
```

Why `-2`?

Because:

```text
1 address = Network address
1 address = Broadcast address
```

Example:

```text
/24
```

Host bits:

```text
32 - 24 = 8
```

Total:

```text
2^8 = 256
```

Usable:

```text
256 - 2 = 254
```

Therefore:

```text
/24 → 254 usable hosts
```

# 17. Subnetting by Required Hosts

Sometimes the question is not:

> "Create 4 subnets."

Instead, it will say:

> "Create a subnet that supports at least 50 hosts."

Let's solve it.

### Requirement

```text
Required hosts = 50
```

We need:

```text
2^h - 2 ≥ 50
```

Try:

```text
2^5 - 2 = 30
```

Not enough.

Next:

```text
2^6 - 2 = 62
```

Enough.

Therefore:

```text
Host bits = 6
```

IPv4 has 32 bits:

```text
32 - 6 = 26
```

Therefore:

```text
CIDR = /26
```

Subnet mask:

```text
255.255.255.192
```

Usable hosts:

```text
62
```

### Answer

For at least 50 hosts:

```text
/26
```

because:

```text
/26 → 62 usable hosts
```

# 20. VLSM — Variable Length Subnet Mask

In real networks, every department may not need the same number of hosts.

Example:

```text
IT          → 100 hosts
HR          → 50 hosts
Finance     → 20 hosts
Management  → 10 hosts
```

Giving everyone `/24` would waste addresses.

Instead we can use:

```text
IT          → /25
HR          → /26
Finance     → /27
Management  → /28
```

This is called:

**VLSM — Variable Length Subnet Masking**

### Malayalam

എല്ലാ department-നും ഒരേ number of IP addresses ആവശ്യമില്ല.

ഉദാഹരണം:

```text
IT          → 100 hosts
HR          → 50 hosts
Finance     → 20 hosts
Management  → 10 hosts
```

അതിനനുസരിച്ച് different subnet sizes നൽകാം.

ഇതാണ്:

**VLSM — Variable Length Subnet Masking**

# 22. Subnetting and Cybersecurity

Subnetting is important for cybersecurity because it enables **network segmentation**.

For example:

```text
Internet
   |
Firewall
   |
   +------ DMZ
   |
   +------ Employee Network
   |
   +------ Server Network
   |
   +------ Security Monitoring Network
   |
   +------ Guest Network
```

You can apply different security policies to different network segments.

### Example

Guest network:

```text
192.168.50.0/24
```

Server network:

```text
192.168.60.0/24
```

Firewall can prevent:

```text
Guest → Server
```

while allowing:

```text
Guest → Internet
```

This is one reason subnetting is important in cybersecurity.

```text
       ↓

       ↓

```

# 27. The 5 Rules You Should Remember

### Rule 1

```text
IPv4 = 32 bits
```

### Rule 2

```text
Host bits = 32 - CIDR
```

### Rule 3

```text
Total addresses = 2^host bits
```

### Rule 4

Traditional usable-host calculation:

```text
Usable hosts = 2^host bits - 2
```

### Rule 5

```text
Block Size = 256 - subnet-mask octet
```

# 28. Final Mental Model

Think of subnetting like **dividing a large apartment building into smaller blocks**.

```text
             LARGE NETWORK
          192.168.1.0/24
                 |
       +---------+---------+
       |         |         |
      /26       /26       /26 ...
       |
       ↓
 Smaller networks
```

**English:**
Subnetting takes one large network and divides it into smaller, manageable networks.

**Malayalam:**
Subnetting ഒരു വലിയ network-നെ ചെറിയ, manageable network-കളായി divide ചെയ്യുന്ന process ആണ്.

For cybersecurity, the important connection is:

```text
Subnetting
    ↓
Network Segmentation
    ↓
Access Control
    ↓
Firewall Rules
    ↓
Reduced Attack Surface
    ↓
Better Security
```

So, as a cybersecurity beginner, don't study subnetting only as an IP-calculation topic. **Understand how subnetting is used to design and secure real networks.**
