# Module 01: Cybersecurity Fundamentals

> Core security concepts, threats, attackers, security teams, lab setup, and how computers and operating systems work.

## 📌 Overview

This module builds the foundation for everything that follows in cybersecurity. It explains what cybersecurity is, the principles it protects (the CIA Triad), who attacks systems and why, and how security teams defend against them. It also covers how to set up a safe practice lab, how to keep up with security research, and the computer and operating system basics every security professional needs.

## 🎯 Topics Covered

- Cybersecurity fundamentals, domains, and the modern threat landscape
- CIA Triad: Confidentiality, Integrity, Availability
- Threats, vulnerabilities, risks, exploits, and attack vectors
- Types of attackers: script kiddies, cyber criminals, insiders, hacktivists, nation-state actors
- Security ecosystem: SOC, Blue Team, Red Team, Purple Team, threat intelligence
- Security lab setup: virtualization, virtual machines, isolated networks, snapshots
- Security research: blogs, CVEs, advisories, responsible disclosure
- Using AI responsibly for security learning
- Operating systems and their role in security
- Computer fundamentals: CPU, RAM, storage, hardware, software, binary

## 💡 Key Concepts

| Concept | In One Line |
|---------|-------------|
| CIA Triad | Confidentiality, Integrity, Availability: the three goals of security |
| Threat | A potential danger that could exploit a weakness |
| Vulnerability | A weakness in a system that can be exploited |
| Risk | Threat × Vulnerability × Impact |
| Authentication vs Authorization | Who you are vs what you are allowed to access |
| Blue / Red / Purple Team | Defend / Attack (ethically) / Improve both |

## 🧠 What I Learned

- Every security control protects confidentiality, integrity, availability, or a mix of them.
- A threat only becomes a problem when it meets a vulnerability, and risk measures how bad that could be.
- Attackers differ in skill and motive, so defences must be layered.
- Security teams work together: the SOC monitors, the Blue Team defends, the Red Team tests, and the Purple Team connects them.
- Practise only in an isolated lab, on systems I own or have permission to test.
- AI is a useful learning aid, but security information must always be verified against trusted sources.
