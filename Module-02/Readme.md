## 🎯 What this module covers

I learned the building blocks every security analyst needs: the principles behind good defence, the main types of malware and attack techniques, how the web is layered, how DoS/DDoS attacks work, how vulnerabilities are tracked and fixed, how to gather open-source intelligence ethically, how to use AI as a research assistant, and how to turn all of it into hands-on practice.
