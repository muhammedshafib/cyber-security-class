# 6. Understand Shell Scripting Fundamentals

**Shell scripting** is the process of writing a sequence of Linux commands into a file so that the shell can execute them automatically.

For cybersecurity, shell scripting is useful for:

* Automating repetitive tasks
* Checking system information
* Monitoring processes
* Managing files
* Analyzing logs
* Performing security checks
* Automating system administration

The most common shell on Linux is **Bash (Bourne Again SHell)**.

---

# a. Variables

A **variable** stores information that can be used later in a script.

### Basic syntax

```bash
name="Shafi"
age=22
```

⚠️ There should be **no spaces** around `=`.

Correct:

```bash
name="Shafi"
```

Wrong:

```bash
name = "Shafi"
```

### Display a variable

Use `$` before the variable name:

```bash
echo $name
```

Output:

```text
Shafi
```

### Example

```bash
#!/bin/bash

name="Shafi"
course="Cyber Security"

echo "Name: $name"
echo "Course: $course"
```

Output:

```text
Name: Shafi
Course: Cyber Security
```

---

## User Input

Use `read` to get information from the user.

```bash
#!/bin/bash

echo "Enter your name:"
read name

echo "Hello $name"
```

Example:

```text
Enter your name:
Shafi
Hello Shafi
```

### `read -p`

You can make it shorter:

```bash
read -p "Enter your name: " name
echo "Hello $name"
```

---

## Command Substitution

You can store the output of a command inside a variable.

```bash
username=$(whoami)
```

Then:

```bash
echo "Current user: $username"
```

Another example:

```bash
current_date=$(date)
echo "Date: $current_date"
```

---

# Special Variables

Bash provides special variables.

| Variable | Meaning                         |
| -------- | ------------------------------- |
| `$0`     | Script name                     |
| `$1`     | First argument                  |
| `$2`     | Second argument                 |
| `$#`     | Number of arguments             |
| `$@`     | All arguments                   |
| `$?`     | Exit status of previous command |
| `$$`     | Current process ID              |

Example:

```bash
#!/bin/bash

echo "Script: $0"
echo "First argument: $1"
echo "Second argument: $2"
```

Run:

```bash
./script.sh hello world
```

Output:

```text
Script: ./script.sh
First argument: hello
Second argument: world
```

# b. Conditional Statements

Conditional statements allow a script to **make decisions**.

The most common structure is:

```bash
if condition
then
    command
fi
```

---

## Basic `if`

```bash
#!/bin/bash

age=20

if [ $age -ge 18 ]
then
    echo "You are an adult"
fi
```

Output:

```text
You are an adult
```

---

## `if...else`

```bash
#!/bin/bash

age=16

if [ $age -ge 18 ]
then
    echo "Adult"
else
    echo "Minor"
fi
```

---

## `if...elif...else`

```bash
#!/bin/bash

marks=75

if [ $marks -ge 90 ]
then
    echo "A+"
elif [ $marks -ge 75 ]
then
    echo "A"
elif [ $marks -ge 50 ]
then
    echo "B"
else
    echo "Fail"
fi
```

---

## Comparison Operators

### Numbers

| Operator | Meaning               |
| -------- | --------------------- |
| `-eq`    | Equal                 |
| `-ne`    | Not equal             |
| `-gt`    | Greater than          |
| `-lt`    | Less than             |
| `-ge`    | Greater than or equal |
| `-le`    | Less than or equal    |

Example:

```bash
if [ $age -ge 18 ]
then
    echo "Allowed"
fi
```

---

## String Comparisons

```bash
if [ "$username" = "admin" ]
then
    echo "Administrator"
fi
```

Common operators:

```text
=       Equal
!=      Not equal
-z      Empty string
-n      Non-empty string
```

Example:

```bash
if [ -z "$name" ]
then
    echo "Name is empty"
fi
```

---

## File Conditions

Shell scripts can check files and directories.

| Test | Meaning               |
| ---- | --------------------- |
| `-f` | Regular file exists   |
| `-d` | Directory exists      |
| `-e` | File/directory exists |
| `-r` | Readable              |
| `-w` | Writable              |
| `-x` | Executable            |

Example:

```bash
if [ -f "/etc/passwd" ]
then
    echo "File exists"
fi
```

Directory:

```bash
if [ -d "/home" ]
then
    echo "Directory exists"
fi
```

# c. Loops

Loops allow you to **repeat commands automatically**.

The main Bash loops are:

1. `for`
2. `while`
3. `until`

---

# 1. For Loop

A `for` loop repeats something for each item.

```bash
#!/bin/bash

for name in Alice Bob Shafi
do
    echo "Hello $name"
done
```

Output:

```text
Hello Alice
Hello Bob
Hello Shafi
```

### Number range

```bash
for i in {1..5}
do
    echo "Number: $i"
done
```

Output:

```text
Number: 1
Number: 2
Number: 3
Number: 4
Number: 5
```

### C-style loop

```bash
for ((i=1; i<=5; i++))
do
    echo $i
done
```

---

# 2. While Loop

A `while` loop continues while a condition is true.

```bash
#!/bin/bash

count=1

while [ $count -le 5 ]
do
    echo "Count: $count"
    ((count++))
done
```

Output:

```text
Count: 1
Count: 2
Count: 3
Count: 4
Count: 5
```

---

# 3. Until Loop

`until` runs until a condition becomes true.

```bash
count=1

until [ $count -gt 5 ]
do
    echo $count
    ((count++))
done
```

---

# Loop Control

### `break`

Stops the loop.

```bash
for i in {1..10}
do
    if [ $i -eq 5 ]
    then
        break
    fi

    echo $i
done
```

Output:

```text
1
2
3
4
```

### `continue`

Skips the current iteration.

```bash
for i in {1..5}
do
    if [ $i -eq 3 ]
    then
        continue
    fi

    echo $i
done
```

Output:

```text
1
2
4
5
```

# d. Functions

A **function** is a reusable block of commands.

Instead of writing the same commands repeatedly, create a function once and call it whenever needed.

### Basic function

```bash
#!/bin/bash

hello() {
    echo "Hello, welcome!"
}

hello
```

Output:

```text
Hello, welcome!
```

---

## Function with Arguments

```bash
#!/bin/bash

greet() {
    echo "Hello $1"
}

greet "Shafi"
```

Output:

```text
Hello Shafi
```

Here:

```text
$1 = first function argument
```

---

## Function with Multiple Arguments

```bash
add() {
    result=$(($1 + $2))
    echo "Result: $result"
}

add 10 20
```

Output:

```text
Result: 30
```

---

## Returning a Status

Bash functions can return an exit status.

```bash
check_file() {
    if [ -f "$1" ]
    then
        return 0
    else
        return 1
    fi
}
```

Use:

```bash
if check_file "/etc/passwd"
then
    echo "File exists"
else
    echo "File not found"
fi
```

# e. Script Execution

Now we need to learn how to actually **create and run a Bash script**.

---

## Step 1 — Create a script

Create a file:

```bash
nano hello.sh
```

Write:

```bash
#!/bin/bash

echo "Hello from Bash!"
```

Save and exit.

In Nano:

```text
Ctrl + O
Enter
Ctrl + X
```

---

# Step 2 — Make it executable

Use:

```bash
chmod +x hello.sh
```

Check permissions:

```bash
ls -l hello.sh
```

You should see an `x`, for example:

```text
-rwxr-xr-x
```

---

# Step 3 — Execute the script

Run:

```bash
./hello.sh
```

Output:

```text
Hello from Bash!
```

---

## Another Way to Execute

You don't always need execute permission if you explicitly invoke Bash:

```bash
bash hello.sh
```

You can also use:

```bash
sh hello.sh
```

However, if the script is specifically written for Bash, prefer:

```bash
bash hello.sh
```

or make it executable and use:

```bash
./hello.sh
```

---

# Shebang

The first line:

```bash
#!/bin/bash
```

is called the **shebang**.

It tells the operating system which interpreter should execute the script.

For Bash:

```bash
#!/bin/bash
```

For an environment-resolved Bash:

```bash
#!/usr/bin/env bash
```

# 🔐 Cybersecurity Example

Shell scripting is extremely useful in cybersecurity.

For example, you can create a simple script that checks whether important files exist:

```bash
#!/bin/bash

echo "Security Check"
echo "==============="

files=(
    "/etc/passwd"
    "/etc/shadow"
    "/etc/hosts"
)

for file in "${files[@]}"
do
    if [ -f "$file" ]
    then
        echo "[+] $file exists"
    else
        echo "[-] $file missing"
    fi
done
```

Run:

```bash
chmod +x security_check.sh
./security_check.sh
```

This demonstrates **variables + arrays + loops + conditions + file checking**.

---

# 🛡️ Log Analysis Example

You can also automate log checking:

```bash
#!/bin/bash

LOG="/var/log/auth.log"

echo "Checking failed login attempts..."

if [ -f "$LOG" ]
then
    grep "Failed password" "$LOG"
else
    echo "Authentication log not found."
fi
```

On systems where authentication logs are stored differently, use the appropriate log source, such as `journalctl`.

# Complete Beginner Script

This combines almost everything you've learned:

```bash
#!/bin/bash

# Function
show_info() {
    echo "Current user: $USER"
    echo "Hostname: $(hostname)"
    echo "Date: $(date)"
}

# Variable
name="Cybersecurity Student"

echo "=============================="
echo " Linux Security Script"
echo "=============================="

echo "Student: $name"

# Function call
show_info

# Condition
if [ "$USER" = "root" ]
then
    echo "[!] Running as root"
else
    echo "[+] Running as normal user"
fi

# Loop
echo
echo "Checking important files:"

for file in /etc/passwd /etc/hosts
do
    if [ -f "$file" ]
    then
        echo "[+] $file exists"
    else
        echo "[-] $file missing"
    fi
done
```
