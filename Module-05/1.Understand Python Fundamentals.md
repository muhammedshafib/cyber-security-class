# 1. Understand Python Fundamentals

If you are starting Python from **zero**, learn these 5 topics in this order:

1. **Variables and Data Types**
2. **Operators**
3. **Input and Output**
4. **Type Conversion**
5. **Python Coding Practices**

---

## 1. Variables and Data Types

### What is a variable?

A **variable** is a name used to store a value.

```python
name = "Shafi"
age = 22
```

Here:

* `name` → variable
* `"Shafi"` → value
* `age` → variable
* `22` → value

Think of a variable like a **box** that stores information.

```text
name ──────> "Shafi"
age  ──────> 22
```

### Common Python data types

| Data Type | Meaning          | Example             |
| --------- | ---------------- | ------------------- |
| `str`     | Text             | `"Hello"`           |
| `int`     | Whole number     | `25`                |
| `float`   | Decimal number   | `25.5`              |
| `bool`    | True/False       | `True`              |
| `list`    | Collection       | `[10, 20, 30]`      |
| `tuple`   | Fixed collection | `(10, 20, 30)`      |
| `set`     | Unique values    | `{10, 20, 30}`      |
| `dict`    | Key-value data   | `{"name": "Shafi"}` |
| `None`    | No value         | `None`              |

### Example

```python
name = "Shafi"
age = 22
height = 5.8
is_student = True

print(name)
print(age)
print(height)
print(is_student)
```

### Check the data type

Use `type()`:

```python
name = "Shafi"
age = 22

print(type(name))
print(type(age))
```

Output:

```text
<class 'str'>
<class 'int'>
```

# 2. Operators

Operators are symbols used to perform operations.

## A. Arithmetic operators

Used for mathematical calculations.

```python
a = 10
b = 3

print(a + b)   # Addition
print(a - b)   # Subtraction
print(a * b)   # Multiplication
print(a / b)   # Division
print(a // b)  # Floor division
print(a % b)   # Remainder
print(a ** b)  # Power
```

Important:

```text
+    Addition
-    Subtraction
*    Multiplication
/    Division
//   Floor division
%    Modulus/remainder
**   Power
```

---

## B. Comparison operators

Used to compare values.

```python
a = 10
b = 5

print(a == b)
print(a != b)
print(a > b)
print(a < b)
print(a >= b)
print(a <= b)
```

Results are `True` or `False`.

For example:

```python
10 > 5
```

Result:

```text
True
```

---

## C. Logical operators

Used to combine conditions.

### `and`

Both conditions must be true.

```python
age = 25

print(age >= 18 and age <= 60)
```

### `or`

At least one condition must be true.

```python
age = 15

print(age < 18 or age > 60)
```

### `not`

Reverses the result.

```python
is_student = True

print(not is_student)
```

---

## D. Assignment operators

```python
x = 10

x += 5
print(x)     # 15

x -= 3
print(x)     # 12

x *= 2
print(x)     # 24
```

Common ones:

```text
=     Assign
+=    Add and assign
-=    Subtract and assign
*=    Multiply and assign
/=    Divide and assign
```

# 3. Input and Output

## Output — `print()`

`print()` displays information on the screen.

```python
print("Hello World")
print("My name is Shafi")
print(100)
```

You can print variables:

```python
name = "Shafi"
age = 22

print(name)
print(age)
```

You can also combine text and variables:

```python
name = "Shafi"
age = 22

print("My name is", name)
print("My age is", age)
```

### Better method: f-string

```python
name = "Shafi"
age = 22

print(f"My name is {name}")
print(f"My age is {age}")
```

---

## Input — `input()`

`input()` gets information from the user.

```python
name = input("Enter your name: ")

print(f"Hello {name}")
```

Example:

```text
Enter your name: Shafi
Hello Shafi
```

### Important beginner point

`input()` normally returns a **string**.

For example:

```python
age = input("Enter your age: ")

print(type(age))
```

Even if you enter:

```text
22
```

Python sees it as:

```text
"22"
```

not:

```text
22
```

This leads to the next topic.

# 4. Type Conversion

Type conversion means changing one data type into another.

### String → Integer

```python
age = "22"

age = int(age)

print(age)
print(type(age))
```

### String → Float

```python
price = "99.50"

price = float(price)

print(price)
```

### Number → String

```python
age = 22

age = str(age)

print(type(age))
```

### Integer → Float

```python
number = 10

number = float(number)

print(number)
```

---

## Very important example

This will cause a problem:

```python
age = input("Enter your age: ")

print(age + 5)
```

Why?

Because `age` is a string.

Correct:

```python
age = int(input("Enter your age: "))

print(age + 5)
```

If you enter:

```text
20
```

Output:

```text
25
```

### Remember

```text
input() → string

int()   → integer
float() → decimal
str()   → string
bool()  → Boolean
```

# 5. Python Coding Practices

Coding practices are rules and habits that make your code **clean, readable, and maintainable**.

## 1. Use meaningful variable names

❌ Bad:

```python
x = "Shafi"
y = 22
```

✅ Better:

```python
name = "Shafi"
age = 22
```

---

## 2. Use `snake_case`

Python commonly uses `snake_case` for variable and function names.

✅

```python
first_name = "Shafi"
student_age = 22
phone_number = "1234567890"
```

Avoid:

```python
studentAge = 22
```

for normal Python variable naming.

---

## 3. Use indentation correctly

Python uses indentation to organize code.

```python
age = 20

if age >= 18:
    print("Adult")
```

The space before `print()` is important.

---

## 4. Add comments when useful

Comments explain your code.

```python
# Store the user's age
age = 22

print(age)
```

Python ignores comments.

---

## 5. Keep code simple

Instead of writing unnecessarily complicated code:

```python
number = 10
result = number + 5

print(result)
```

Keep your beginner programs clear and easy to understand.

---

## 6. Follow the DRY principle

**DRY = Don't Repeat Yourself**

Instead of repeating the same code many times, later you can use functions.

For example, instead of:

```python
print("Hello Shafi")
print("Hello Ahmed")
print("Hello Ali")
```

you will eventually learn functions to make reusable code.
