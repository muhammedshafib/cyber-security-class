# 3. Understand Python Collections

Python **collections** are used to store multiple values in a single variable.

Instead of:

```python
name1 = "Shafi"
name2 = "Ali"
name3 = "Ahmed"
```

you can use:

```python
names = ["Shafi", "Ali", "Ahmed"]
```

The four main Python collections are:

```text
List        → []
Tuple       → ()
Set         → {}
Dictionary  → {"key": "value"}
```

---

# 1. Lists

A **list** stores multiple values in an ordered collection.

```python
names = ["Shafi", "Ali", "Ahmed"]
```

A list can contain different data types:

```python
data = ["Shafi", 22, 5.8, True]
```

### Important properties

* Ordered
* Changeable (**mutable**)
* Allows duplicate values
* Supports indexing

---

## Access list items

Python indexes start from **0**.

```python
names = ["Shafi", "Ali", "Ahmed"]

print(names[0])
print(names[1])
print(names[2])
```

Output:

```text
Shafi
Ali
Ahmed
```

Think:

```text
Index:    0        1       2
          ↓        ↓       ↓
        Shafi     Ali    Ahmed
```

### Negative indexing

```python
print(names[-1])
```

Output:

```text
Ahmed
```

`-1` means the last item.

---

## Change a list item

```python
names = ["Shafi", "Ali", "Ahmed"]

names[1] = "Rahul"

print(names)
```

Output:

```text
['Shafi', 'Rahul', 'Ahmed']
```

---

## Add items

### `append()`

Adds an item at the end.

```python
names = ["Shafi", "Ali"]

names.append("Ahmed")

print(names)
```

Result:

```text
['Shafi', 'Ali', 'Ahmed']
```

### `insert()`

Adds an item at a specific position.

```python
names.insert(1, "Rahul")

print(names)
```

---

## Remove items

### `remove()`

```python
names.remove("Ali")
```

### `pop()`

Removes an item using its index.

```python
names.pop(1)
```

If no index is given:

```python
names.pop()
```

it removes the last item.

### `del`

```python
del names[0]
```

---

## Useful list functions

```python
numbers = [10, 20, 30, 40]

print(len(numbers))
print(max(numbers))
print(min(numbers))
print(sum(numbers))
```

---

# 2. Tuples

A **tuple** is similar to a list, but it is **immutable**.

```python
coordinates = (10, 20)
```

Once created, you normally cannot change its items.

```python
coordinates[0] = 50
```

This produces an error.

### Tuple properties

* Ordered
* Immutable
* Allows duplicates
* Supports indexing

Example:

```python
colors = ("red", "green", "blue")

print(colors[0])
print(colors[1])
```

---

## Why use tuples?

Use a tuple when the data should not be changed.

Example:

```python
server_ip = ("192.168.1.10", 443)
```

You can think:

```text
List  → Data can change
Tuple → Data should stay fixed
```

---

# 3. Sets

A **set** stores unique values.

```python
numbers = {10, 20, 30, 10, 20}

print(numbers)
```

Output will contain each value only once:

```text
{10, 20, 30}
```

### Set properties

* Unique values
* No duplicate elements
* Unordered
* Mutable

---

## Add to a set

```python
ports = {22, 80, 443}

ports.add(8080)

print(ports)
```

---

## Remove from a set

```python
ports.remove(80)
```

You can also use:

```python
ports.discard(80)
```

`discard()` does not raise an error if the value doesn't exist.

---

## Set operations

Sets are especially useful for comparing groups of data.

### Union

Combines two sets.

```python
a = {1, 2, 3}
b = {3, 4, 5}

print(a | b)
```

Result:

```text
{1, 2, 3, 4, 5}
```

### Intersection

Finds common values.

```python
print(a & b)
```

Result:

```text
{3}
```

### Difference

Finds values in `a` but not `b`.

```python
print(a - b)
```

Result:

```text
{1, 2}
```

### Cybersecurity example

Suppose you have IP addresses from two logs:

```python
log1_ips = {"10.0.0.1", "10.0.0.2", "10.0.0.3"}
log2_ips = {"10.0.0.2", "10.0.0.4"}

common_ips = log1_ips & log2_ips

print(common_ips)
```

Output:

```text
{'10.0.0.2'}
```

This kind of operation becomes useful in **log analysis and security automation**.

# 4. Dictionaries

A **dictionary** stores data as:

```text
key → value
```

Example:

```python
student = {
    "name": "Shafi",
    "age": 22,
    "course": "Cyber Security"
}
```

Think:

```text
"name"   → "Shafi"
"age"    → 22
"course" → "Cyber Security"
```

---

## Access dictionary values

```python
print(student["name"])
print(student["age"])
```

Output:

```text
Shafi
22
```

---

## Add a new item

```python
student["city"] = "Kerala"
```

---

## Change a value

```python
student["age"] = 23
```

---

## Remove a value

```python
student.pop("city")
```

---

## Check whether a key exists

```python
if "name" in student:
    print("Name exists")
```

---

## Loop through a dictionary

```python
student = {
    "name": "Shafi",
    "age": 22,
    "course": "Cyber Security"
}

for key, value in student.items():
    print(key, ":", value)
```

Output:

```text
name : Shafi
age : 22
course : Cyber Security
```

---

# 🛡️ Cybersecurity Dictionary Example

Dictionaries are extremely useful when representing structured security information.

```python
server = {
    "ip": "192.168.1.10",
    "port": 443,
    "protocol": "HTTPS",
    "status": "open"
}

print(server["ip"])
print(server["port"])
print(server["status"])
```

You can later use dictionaries when working with:

* Log records
* Network information
* Vulnerability information
* User information
* Configuration data
* API/JSON data

# 5. Collection Manipulation

**Collection manipulation** means adding, removing, searching, sorting, and processing collection data.

---

## A. Loop through a list

```python
ports = [22, 80, 443, 8080]

for port in ports:
    print(port)
```

---

## B. Search for an item

```python
ports = [22, 80, 443]

if 443 in ports:
    print("HTTPS port found")
```

---

## C. Sort a list

```python
numbers = [50, 10, 40, 20, 30]

numbers.sort()

print(numbers)
```

Output:

```text
[10, 20, 30, 40, 50]
```

Reverse:

```python
numbers.sort(reverse=True)
```

---

## D. Reverse a list

```python
numbers = [1, 2, 3, 4, 5]

numbers.reverse()

print(numbers)
```

Output:

```text
[5, 4, 3, 2, 1]
```

---

# List Slicing

Slicing allows you to get part of a collection.

```python
numbers = [10, 20, 30, 40, 50]

print(numbers[1:4])
```

Output:

```text
[20, 30, 40]
```

Think:

```text
Index:    0    1    2    3    4
Value:   10   20   30   40   50
              ↑         ↑
             start     stop
```

The stop index is **not included**.

---

# List Comprehension

Once you understand normal loops, learn **list comprehension**.

Instead of:

```python
numbers = []

for i in range(1, 6):
    numbers.append(i * 2)

print(numbers)
```

You can write:

```python
numbers = [i * 2 for i in range(1, 6)]

print(numbers)
```

Output:

```text
[2, 4, 6, 8, 10]
```

Don't worry if this looks difficult initially. First become comfortable with normal `for` loops.

# ⭐ List vs Tuple vs Set vs Dictionary

| Feature      | List               | Tuple      | Set                          | Dictionary     |
| ------------ | ------------------ | ---------- | ---------------------------- | -------------- |
| Syntax       | `[]`               | `()`       | `{}`                         | `{key: value}` |
| Ordered      | ✅                  | ✅          | No guaranteed indexing order | ✅              |
| Changeable   | ✅                  | ❌          | ✅                            | ✅              |
| Duplicates   | ✅                  | ✅          | ❌                            | Keys ❌         |
| Indexing     | ✅                  | ✅          | ❌                            | By key         |
| Main purpose | General collection | Fixed data | Unique data                  | Key-value data |

### Easy memory trick

```text
LIST
↓
"I need an ordered collection that I can change."

TUPLE
↓
"I need an ordered collection that should not change."

SET
↓
"I only want unique values."

DICTIONARY
↓
"I need KEY → VALUE information."
```

# 🧪 Practice Program

Try this yourself in VS Code:

```python
servers = [
    {
        "ip": "192.168.1.10",
        "port": 22,
        "status": "open"
    },
    {
        "ip": "192.168.1.20",
        "port": 443,
        "status": "open"
    },
    {
        "ip": "192.168.1.30",
        "port": 80,
        "status": "closed"
    }
]

for server in servers:
    print(f"IP: {server['ip']}")
    print(f"Port: {server['port']}")
    print(f"Status: {server['status']}")
    print("---")
```

This is a very important pattern:

```text
List
  ↓
Dictionary
  ↓
Loop
  ↓
Access values
```

You'll see this structure frequently when working with **JSON, APIs, logs, and cybersecurity automation**.
