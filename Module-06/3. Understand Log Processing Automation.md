# 3. Understand Log Processing Automation

**Log processing automation** means using Python to automatically collect, read, analyze, connect, and report information from log files.

This is very important in cybersecurity because computers continuously generate logs.

A simple workflow is:

```text
LOG FILES
   ↓
1. Collect logs
   ↓
2. Parse logs
   ↓
3. Extract events
   ↓
4. Correlate events
   ↓
5. Generate report
```

Let's understand each part with simple Python.

---

# 3.1 Log Collection

## What is a log?

A **log** is a record of something that happened on a computer, application, server, or network.

Example:

```text
Successful login: alice
Failed login: admin
Failed login: root
File accessed: report.pdf
```

A security log might contain:

```text
2026-09-12 10:00 Failed login alice 192.168.1.10
2026-09-12 10:02 Successful login bob 192.168.1.20
2026-09-12 10:03 Failed login admin 192.168.1.10
```

---

## What is log collection?

**Log collection** means getting logs from their source so they can be analyzed.

For beginner Python, we'll start with a local file:

```text
auth.log
```

Example:

```text
Failed login alice 192.168.1.10
Successful login bob 192.168.1.20
Failed login admin 192.168.1.10
```

Python:

```python
with open("auth.log", "r") as file:
    for line in file:
        print(line.strip())
```

### Explanation

```python
open("auth.log", "r")
```

Opens the log for reading.

```python
for line in file:
```

Reads it one line at a time.

```python
line.strip()
```

Removes unnecessary whitespace/newline characters.

### Mental model

```text
auth.log
   ↓
open()
   ↓
read line
   ↓
process line
```

---

# 3.2 Log Parsing

## What is parsing?

**Parsing** means taking a raw log line and separating it into useful pieces.

Suppose we have:

```text
Failed login alice 192.168.1.10
```

We can use:

```python
line.split()
```

Result:

```python
["Failed", "login", "alice", "192.168.1.10"]
```

Now Python can work with each part separately.

---

## Simple parsing example

```python
line = "Failed login alice 192.168.1.10"

parts = line.split()

print(parts)
```

Output:

```text
['Failed', 'login', 'alice', '192.168.1.10']
```

We can access individual values:

```python
print(parts[0])
print(parts[1])
print(parts[2])
print(parts[3])
```

Output:

```text
Failed
login
alice
192.168.1.10
```

---

## Extracting the IP

Because the IP is the last field:

```python
ip = parts[-1]

print(ip)
```

Output:

```text
192.168.1.10
```

Remember:

```text
[-1] = last item
```

---

# 3.3 Event Extraction

Now we want to identify **what actually happened**.

Suppose:

```text
Failed login alice 192.168.1.10
Successful login bob 192.168.1.20
Failed login admin 192.168.1.10
```

There are different events:

```text
Failed login
Successful login
Failed login
```

We can extract failed login events.

```python
with open("auth.log", "r") as file:

    for line in file:

        if "Failed login" in line:
            print("Failed login detected")
```

Output:

```text
Failed login detected
Failed login detected
```

---

# Extract the User and IP

Let's make it slightly more useful.

```python
with open("auth.log", "r") as file:

    for line in file:

        if "Failed login" in line:

            parts = line.split()

            username = parts[2]
            ip = parts[3]

            print("User:", username)
            print("IP:", ip)
```

For:

```text
Failed login alice 192.168.1.10
```

we get:

```text
User: alice
IP: 192.168.1.10
```

### Important

This code assumes the log format is exactly:

```text
Failed login USER IP
```

Real logs often have timestamps and additional fields, so parsing rules must match the actual log format.

# 3.4 Event Correlation

This is one of the most important concepts.

## What is correlation?

**Correlation means connecting multiple events together to identify a larger pattern.**

One event might not be very interesting.

For example:

```text
Failed login from 10.0.0.5
```

One failed login is normal.

But:

```text
Failed login from 10.0.0.5
Failed login from 10.0.0.5
Failed login from 10.0.0.5
Failed login from 10.0.0.5
Failed login from 10.0.0.5
```

Now we have a pattern.

We can correlate these events by IP address.

---

# Simple Correlation with `Counter`

```python
from collections import Counter

failed_ips = []

with open("auth.log", "r") as file:

    for line in file:

        if "Failed login" in line:

            ip = line.split()[-1]

            failed_ips.append(ip)

counts = Counter(failed_ips)

for ip, count in counts.items():

    print(ip, "→", count, "failed attempts")
```

Suppose the log contains:

```text
Failed login alice 10.0.0.5
Failed login bob 10.0.0.8
Failed login admin 10.0.0.5
Failed login test 10.0.0.5
```

The list becomes:

```python
[
    "10.0.0.5",
    "10.0.0.8",
    "10.0.0.5",
    "10.0.0.5"
]
```

`Counter` produces:

```text
10.0.0.5 → 3
10.0.0.8 → 1
```

That's basic event correlation.

# 3.5 Automated Reporting

After analyzing the logs, we want Python to produce a useful report.

Example:

```text
SECURITY REPORT
----------------
Failed login attempts: 4

IP addresses:

10.0.0.5 → 3
10.0.0.8 → 1
```

Python:

```python
from collections import Counter

failed_ips = []

with open("auth.log", "r") as file:

    for line in file:

        if "Failed login" in line:

            ip = line.split()[-1]
            failed_ips.append(ip)

counts = Counter(failed_ips)

print("SECURITY REPORT")
print("----------------")

print("Failed login attempts:", len(failed_ips))

print()
print("IP addresses:")

for ip, count in counts.items():
    print(ip, "→", count)
```

# 3.6 Add an Alert

Now we can make the report more useful.

Suppose:

```text
3 or more failures
```

should produce a warning.

```python
from collections import Counter

failed_ips = []

with open("auth.log", "r") as file:

    for line in file:

        if "Failed login" in line:

            ip = line.split()[-1]
            failed_ips.append(ip)

counts = Counter(failed_ips)

print("SECURITY REPORT")
print("----------------")

for ip, count in counts.items():

    print(ip, "→", count, "failed attempts")

    if count >= 3:
        print("WARNING: Multiple failed attempts")
```

Output:

```text
SECURITY REPORT
----------------
10.0.0.5 → 3 failed attempts
WARNING: Multiple failed attempts
10.0.0.8 → 1 failed attempts
```

# 3.7 Complete Log Automation Project

Now let's combine everything:

```text
Collect
   ↓
Parse
   ↓
Extract
   ↓
Correlate
   ↓
Report
```

### Complete beginner project

```python
from collections import Counter

failed_ips = []

# 1. Collect logs
with open("auth.log", "r") as file:

    # 2. Parse each line
    for line in file:

        # 3. Extract failed login events
        if "Failed login" in line:

            ip = line.split()[-1]

            failed_ips.append(ip)


# 4. Correlate events
counts = Counter(failed_ips)


# 5. Automated report
print("SECURITY REPORT")
print("----------------")

print("Total failed attempts:", len(failed_ips))

print()

for ip, count in counts.items():

    print(ip, "→", count, "failed attempts")

    if count >= 3:
        print("WARNING: Suspicious activity")
```
