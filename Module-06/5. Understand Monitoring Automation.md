# 5. Understand Monitoring Automation

**Monitoring automation** means using Python to continuously or repeatedly check a computer, service, file, or system condition and then report or alert when something changes.

A simple workflow is:

```text
System / Service / File
          ↓
       Monitor
          ↓
    Detect change/problem
          ↓
       Check rule
          ↓
        Alert
          ↓
      Take action
```

We'll keep the examples **simple and beginner-friendly**, using your own Windows computer or localhost for practice.

---

# 5.1 System Monitoring

## What is system monitoring?

System monitoring means checking the condition of a computer.

We can monitor things such as:

* CPU usage
* Memory usage
* Disk usage
* Running processes
* Operating-system information
* Network information

For Python, a useful third-party library is **psutil**.

# 5.2 Service Monitoring

## What is a service?

A service is a program that performs a function in the background.

Examples:

```text
Web server
Database server
DNS service
SSH service
```

A service may listen on a network port.

For example:

```text
HTTP  → 80
HTTPS → 443
```

Instead of manually checking whether a service is reachable, Python can do it.

---

# Simple Service Monitor

We'll use localhost:

```python
import socket

host = "127.0.0.1"
port = 80

sock = socket.socket(socket.AF_INET, socket.SOCK_STREAM)
sock.settimeout(2)

try:
    sock.connect((host, port))
    print("Service is UP")

except socket.timeout:
    print("Service check timed out")

except ConnectionRefusedError:
    print("Service is DOWN")

finally:
    sock.close()
```

### What happens?

```text
Connect to localhost:80
          ↓
       Success?
       /      \
     YES       NO
      ↓         ↓
     UP        DOWN
```

This connects directly to the **Network Automation** topic you learned earlier.

---

# Service Monitoring Function

We can make the code reusable:

```python
import socket

def check_service(host, port):

    sock = socket.socket(socket.AF_INET, socket.SOCK_STREAM)
    sock.settimeout(2)

    try:
        sock.connect((host, port))
        return True

    except (socket.timeout, ConnectionRefusedError):
        return False

    finally:
        sock.close()


if check_service("127.0.0.1", 80):
    print("Service is UP")
else:
    print("Service is DOWN")
```

Now:

```python
check_service(host, port)
```

can be reused for different authorized systems and services.

# 5.3 File Monitoring

## What is file monitoring?

File monitoring means watching a file to see whether it exists, changes, or has been modified.

This can be useful for:

* Configuration files
* Security logs
* Important documents
* Application files
* Integrity checking

For example:

```text
config.txt
```

We can check whether it exists.

```python
import os

if os.path.exists("config.txt"):
    print("File exists")

else:
    print("File does not exist")
```

---

# Checking File Size

```python
import os

size = os.path.getsize("config.txt")

print("File size:", size, "bytes")
```

This can help detect unexpected changes.

For example:

```text
Before:
config.txt → 500 bytes

After:
config.txt → 2,500 bytes
```

That could indicate that something changed.

---

# 5.4 Change Detection

There are several ways to detect changes.

A simple method is checking the file's modification time.

```python
import os

time = os.path.getmtime("config.txt")

print(time)
```

This returns the modification timestamp.

---

## Better Method: SHA-256

For security-related integrity checking, we can calculate a hash.

```python
import hashlib

with open("config.txt", "rb") as file:
    data = file.read()

hash_value = hashlib.sha256(data).hexdigest()

print("SHA-256:", hash_value)
```

Example:

```text
SHA-256: 8f4c...abc1
```

The hash represents the file's contents.

---

# How Change Detection Works

First calculate the original hash:

```text
config.txt
    ↓
SHA-256
    ↓
ABC123
```

Later calculate it again:

```text
config.txt
    ↓
SHA-256
    ↓
ABC123
```

Same:

```text
ABC123 == ABC123
```

The file contents haven't changed.

But if you get:

```text
ABC123 != XYZ789
```

the file contents have changed.

---

# Simple File Integrity Checker

```python
import hashlib

def get_hash(filename):

    with open(filename, "rb") as file:
        data = file.read()

    return hashlib.sha256(data).hexdigest()


original_hash = get_hash("config.txt")

print("Original hash:")
print(original_hash)
```

Now we can compare a later hash.

```python
current_hash = get_hash("config.txt")

if current_hash == original_hash:
    print("File has not changed")

else:
    print("ALERT: File has changed")
```

---

# Why SHA-256?

Suppose:

```text
Original file:
Hello World
```

Hash:

```text
ABC123...
```

Someone changes the file:

```text
Hello World!
```

Hash:

```text
XYZ789...
```

Even a small content change normally produces a different SHA-256 digest.

This is called **file integrity checking**.

# 5.5 Alerting Workflows

Now we combine monitoring and alerts.

## What is an alerting workflow?

An alerting workflow defines:

```text
What to monitor?
       ↓
What condition matters?
       ↓
What threshold?
       ↓
What happens when threshold is reached?
```

For example:

```text
CPU usage
    ↓
Is CPU >= 80%?
    ↓
YES
    ↓
Generate alert
```

---

# Simple Alert

```python
cpu = 85

if cpu >= 80:
    print("ALERT: High CPU usage")
```

---

# Multiple Conditions

```python
cpu = 85
memory = 60

if cpu >= 80:
    print("ALERT: High CPU")

if memory >= 80:
    print("ALERT: High memory")

    print("ALERT: Disk space is high")
```

Output:

```text
ALERT: High CPU
ALERT: Disk space is high
```

# 5.7 Monitoring in a Loop

A monitoring system often checks repeatedly.

```python
import time
import psutil

while True:

    cpu = psutil.cpu_percent()

    print("CPU:", cpu, "%")

    if cpu >= 80:
        print("ALERT: High CPU usage")

    time.sleep(5)
```

### What happens?

```text
Check CPU
   ↓
Print CPU
   ↓
Check threshold
   ↓
Alert if needed
   ↓
Wait 5 seconds
   ↓
Check again
   ↓
Repeat
```

### Important

This:

```python
while True:
```

creates an endless loop.

Stop it in the terminal with:

```text
Ctrl + C
```

# 5.8 Better Monitoring Workflow

Instead of putting everything into one large script, use functions.

```python
import psutil

def check_cpu():

    cpu = psutil.cpu_percent()

    print("CPU:", cpu, "%")

    if cpu >= 80:
        print("ALERT: High CPU usage")


def check_memory():

    memory = psutil.virtual_memory().percent

    print("Memory:", memory, "%")

    if memory >= 80:
        print("ALERT: High memory usage")


check_cpu()
check_memory()
```

This is better because each function has one responsibility.

# 5.11 Monitoring vs Change Detection

These concepts are related but different.

### Monitoring

Asks:

> "What is the current condition?"

Example:

```text
CPU = 85%
```

### Change detection

Asks:

> "Has something changed?"

Example:

```text
File hash before = ABC
File hash now    = XYZ
```

So:

```text
Monitoring → Current state

Change detection → Difference between states
```

# 5.12 Real Security Monitoring Concept

A simple security monitoring system could look like:

```text
             SYSTEM
                ↓
       ┌─────────────────┐
       │     Monitor     │
       └─────────────────┘
          ↓      ↓      ↓
        CPU    Files   Services
          ↓      ↓      ↓
       Threshold / Change
                ↓
          ┌───────────┐
          │   Alert   │
          └───────────┘
                ↓
           SOC Analyst
```

For example:

```text
File changed
     ↓
SHA-256 changed
     ↓
Generate alert
     ↓
Analyst investigates
```

---

# 5.13 Important Security Principle

Monitoring should usually **detect and report first**.

For example:

```text
Detection
   ↓
Alert
   ↓
Investigation
   ↓
Authorized response
```

Don't automatically perform destructive actions just because a condition was detected.

For example, don't automatically delete files or disable accounts based on a simple beginner rule.
