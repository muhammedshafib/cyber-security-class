# 2. Understand HTML Fundamentals

HTML is the **basic structure of a web page**. Since you're learning web fundamentals for cybersecurity, it's important to understand not only what HTML does, but also how **forms and user input** move through a web application.

---

# 1. HTML Structure

### What is HTML?

**HTML = HyperText Markup Language**

HTML tells the browser:

> **What elements should appear on the webpage and how they are organized.**

HTML is **not a programming language**. It is a **markup language**.

For example:

```html
<h1>Hello</h1>
<p>Welcome to my website.</p>
```

The browser displays:

```text
Hello
Welcome to my website.
```

---

## Basic HTML document

```html
<!DOCTYPE html>

<html>
<head>
    <title>My Website</title>
</head>

<body>
    <h1>Hello World</h1>
    <p>Welcome to my website.</p>
</body>
</html>
```

Let's understand it.

### `<!DOCTYPE html>`

Tells the browser:

> "This document uses modern HTML."

---

### `<html>`

The **root element** of the page.

Everything normally goes inside:

```html
<html>
    ...
</html>
```

---

### `<head>`

Contains information **about the webpage**.

Example:

```html
<head>
    <title>My Website</title>
</head>
```

The `<head>` can contain:

* page title
* metadata
* CSS links
* scripts
* other browser-related information

Much of this isn't directly displayed as page content.

---

### `<title>`

Defines the page title shown in the browser tab.

```html
<title>My Website</title>
```

---

### `<body>`

Contains the **visible webpage content**.

```html
<body>
    <h1>Hello</h1>
    <p>Welcome!</p>
</body>
```

---

## Basic structure to remember

```text
HTML
│
├── HEAD
│   └── Information about page
│
└── BODY
    └── Visible content
```

---

# 2. HTML Forms

A **form** is used to collect information from a user.

Examples:

* Login
* Registration
* Search
* Contact form
* Feedback
* Payment information

Basic example:

```html
<form>
    <input type="text">
    <input type="password">
    <button>Login</button>
</form>
```

It might look like:

```text
Username: [____________]

Password: [____________]

             [ Login ]
```

---

## `<form>`

The `<form>` element creates a form.

```html
<form>
    ...
</form>
```

It groups the user-input elements together.

---

## `action`

`action` specifies **where the form data should be sent**.

Example:

```html
<form action="/login">
```

Conceptually:

```text
User
 ↓
Form
 ↓
/login
 ↓
Server
```

---

## `method`

`method` specifies **how the form data is sent**.

Two common methods are:

```html
<form method="GET">
```

and

```html
<form method="POST">
```

### GET

Usually used for requesting/searching information.

Example:

```text
/search?q=python
```

### POST

Commonly used when submitting data to the server.

For example:

```text
Login information
Registration information
```

Important:

> `POST` does **not automatically mean encrypted or secure**. HTTPS is what protects data in transit.

---

# 3. User Inputs

User input means:

> **Information entered or selected by the user.**

HTML provides several input types.

---

## Text input

```html
<input type="text">
```

Used for things like:

```text
Name
Username
City
```

---

## Password input

```html
<input type="password">
```

The browser hides the characters:

```text
Password: ********
```

Important:

> `type="password"` only hides the characters on the screen. It does not itself encrypt the password.

---

## Email input

```html
<input type="email">
```

Used for email addresses.

```text
Email: [user@example.com]
```

Browsers can perform some basic input checking.

---

## Number input

```html
<input type="number">
```

Used for numeric values.

```text
Age: [25]
```

---

## Checkbox

```html
<input type="checkbox">
```

Allows users to select options.

Example:

```text
☐ Accept terms
```

---

## Radio button

```html
<input type="radio" name="gender">
```

Radio buttons are commonly used when selecting **one option from a group**.

```text
○ Option A
○ Option B
○ Option C
```

---

## Submit button

```html
<button type="submit">Login</button>
```

Used to submit the form.

---

# `name` attribute

The `name` attribute is very important when sending form data.

Example:

```html
<input type="text" name="username">
<input type="password" name="password">
```

If the user enters:

```text
username = shafi
password = 12345
```

the form can send data conceptually like:

```text
username=shafi
password=12345
```

So remember:

> **`name` identifies the input when form data is submitted.**

---

# `value` attribute

`value` represents the value associated with an element.

Example:

```html
<input type="text" name="username" value="shafi">
```

The field initially contains:

```text
shafi
```

---

# 4. Document Structure

HTML documents use different elements to organize content.

A simple webpage can be structured like this:

```text
<html>
│
├── <head>
│
└── <body>
    │
    ├── <header>
    │
    ├── <nav>
    │
    ├── <main>
    │   │
    │   ├── <section>
    │   └── <article>
    │
    └── <footer>
```

Let's understand each one.

---

## `<header>`

Contains introductory or top-page content.

Example:

```html
<header>
    <h1>My Website</h1>
</header>
```

Usually contains:

* logo
* website title
* introductory content

---

## `<nav>`

Contains navigation links.

```html
<nav>
    <a href="/">Home</a>
    <a href="/about">About</a>
    <a href="/contact">Contact</a>
</nav>
```

---

## `<main>`

Contains the **main content** of the page.

```html
<main>
    <h1>Welcome</h1>
    <p>This is the main content.</p>
</main>
```

---

## `<section>`

Groups related content.

```html
<section>
    <h2>About Us</h2>
    <p>We build websites.</p>
</section>
```

---

## `<article>`

Represents an independent piece of content.

Examples:

* Blog post
* News article
* Forum post

```html
<article>
    <h2>My Blog Post</h2>
    <p>This is my article.</p>
</article>
```

---

## `<footer>`

Usually contains information at the bottom of the page.

```html
<footer>
    Copyright 2026
</footer>
```

---

# 5. Web Page Components

HTML provides many elements for creating webpage content.

## Heading

```html
<h1>Main Heading</h1>
```

HTML has:

```text
<h1> → Most important heading
<h2> → Subheading
<h3> → Smaller heading
...
<h6> → Lowest-level heading
```

---

## Paragraph

```html
<p>Hello, welcome to my website.</p>
```

`<p>` creates a paragraph.

---

## Link

```html
<a href="https://example.com">Visit Website</a>
```

Remember:

```text
<a>     → creates the link
href    → tells where the link goes
```

---

## Image

```html
<img src="photo.jpg" alt="My photo">
```

Remember:

```text
<img>   → displays image
src     → image location
alt     → alternative text
```

---

## Button

```html
<button>Login</button>
```

Creates a clickable button.

---

## List

### Unordered list

```html
<ul>
    <li>Python</li>
    <li>HTML</li>
    <li>CSS</li>
</ul>
```

Result:

```text
• Python
• HTML
• CSS
```

### Ordered list

```html
<ol>
    <li>Open browser</li>
    <li>Enter website</li>
    <li>Login</li>
</ol>
```

Result:

```text
1. Open browser
2. Enter website
3. Login
```

# Complete Example

Now let's combine the concepts:

```html
<!DOCTYPE html>

<html>

<head>
    <title>Login Page</title>
</head>

<body>

    <header>
        <h1>My Website</h1>
    </header>

    <nav>
        <a href="/">Home</a>
        <a href="/about">About</a>
    </nav>

    <main>

        <h2>Login</h2>

        <form action="/login" method="POST">

            <label>Username:</label>
            <input type="text" name="username">

            <br>

            <label>Password:</label>
            <input type="password" name="password">

            <br>

            <button type="submit">Login</button>

        </form>

    </main>

    <footer>
        Copyright 2026
    </footer>

</body>

</html>
```

The structure is:

```text
Web Page
│
├── Header
│   └── Website title
│
├── Navigation
│   ├── Home
│   └── About
│
├── Main
│   └── Login Form
│       ├── Username input
│       ├── Password input
│       └── Login button
│
└── Footer
```

# 🔐 HTML + Cybersecurity

This is especially important for your cybersecurity learning.

Consider:

```text
User
 ↓
HTML Form
 ↓
User Input
 ↓
HTTP Request
 ↓
Backend
 ↓
Database
```

For example:

```html
<input type="text" name="username">
```

The user controls the value entered into this field.

Therefore:

> **User input should always be treated as untrusted data until the application properly validates and handles it.**

This concept becomes important when learning:

```text
XSS
SQL Injection
CSRF
Command Injection
Input Validation
Authentication
Authorization
```

### The most important mental model

```text
HTML
 ↓
Creates webpage structure
 ↓
Forms collect user input
 ↓
Browser sends input
 ↓
HTTP request
 ↓
Backend processes it
 ↓
Response comes back
 ↓
Browser displays result
```

If you understand this flow, you have the **core HTML knowledge needed before moving into CSS, JavaScript, HTTP, and web application security**.
