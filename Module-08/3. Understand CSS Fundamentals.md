# 3. Understand CSS Fundamentals

## What is CSS?

**CSS = Cascading Style Sheets**

CSS is used to control the **appearance and layout of an HTML webpage**.

Remember:

```text
HTML       → Structure
CSS        → Design / Appearance
JavaScript → Behaviour / Actions
```

Example:

```html
<h1>Hello World</h1>
```

HTML creates the heading.

CSS can make it:

```css
h1 {
    color: blue;
    font-size: 30px;
}
```

So:

```text
HTML → "What is on the page?"
CSS  → "How does it look and where does it appear?"
```

---

# 1. Styling Concepts

Styling means changing how HTML elements **look**.

## Basic CSS syntax

```css
selector {
    property: value;
}
```

Example:

```css
h1 {
    color: blue;
    font-size: 30px;
}
```

Understand it as:

```text
h1          → Which element?
color       → What do we change?
blue        → What value?
font-size   → What do we change?
30px        → What value?
```

---

## A. Color

Change text color:

```css

```

Change background color:

```css

```

# The CSS Box Model

This is **very important**.

Every HTML element can be thought of as a box:

```text
┌───────────────────────────┐
│          Margin           │
│  ┌─────────────────────┐  │
│  │       Border        │  │
│  │  ┌───────────────┐  │  │
│  │  │    Padding    │  │  │
│  │  │  ┌─────────┐  │  │  │
│  │  │  │ Content │  │  │  │
│  │  │  └─────────┘  │  │  │
│  │  └───────────────┘  │  │
│  └─────────────────────┘  │
└───────────────────────────┘
```

### Content

The actual content.

```text
Hello
```

### Padding

Space **inside** the element around the content.

```css
button {
    padding: 10px;
}
```

### Border

The line around the element.

```css
button {
    border: 1px solid black;
}
```

### Margin

Space **outside** the element.

```css
button {
    margin: 10px;
}
```

### Easy memory

```text
Margin  → Outside
Border  → Edge
Padding → Inside
Content → Actual content
```

# 2. Layout Systems

Layout means:

> **How elements are positioned and arranged on the page.**

Two very important CSS layout systems are:

```text
Flexbox
Grid
```

---

# A. Flexbox

**Flexbox** is useful for arranging elements in a row or column.

Example:

```css
.container {
    display: flex;
}
```

HTML:

```html
<div class="container">
    <div>Box 1</div>
    <div>Box 2</div>
    <div>Box 3</div>
</div>
```

Without layout control, elements may appear differently depending on their type.

With Flexbox:

```text
┌───────┐ ┌───────┐ ┌───────┐
│ Box 1 │ │ Box 2 │ │ Box 3 │
└───────┘ └───────┘ └───────┘
```

---

## Important Flexbox properties

### `display: flex`

Turns an element into a flex container.

```css
.container {
    display: flex;
}
```

### `justify-content`

Controls alignment along the main direction.

```css
.container {
    display: flex;
    justify-content: center;
}
```

### `align-items`

Controls alignment across the other direction.

```css
.container {
    display: flex;
    align-items: center;
}
```

### `gap`

Creates space between items.

```css
.container {
    display: flex;
    gap: 20px;
}
```

---

# B. CSS Grid

**Grid** is useful when you need rows and columns.

Example:

```css
.container {
    display: grid;
    grid-template-columns: 1fr 1fr 1fr;
}
```

Conceptually:

```text
┌────────┬────────┬────────┐
│ Box 1  │ Box 2  │ Box 3  │
├────────┼────────┼────────┤
│ Box 4  │ Box 5  │ Box 6  │
└────────┴────────┴────────┘
```

### Flexbox vs Grid

```text
Flexbox → Usually one-dimensional
           Row OR column

Grid    → Two-dimensional
           Rows AND columns
```

---

# C. Positioning

CSS can also control an element's position.

Common values:

```css
position: static;
position: relative;
position: absolute;
position: fixed;
position: sticky;
```

For beginner understanding:

### `static`

Normal position.

### `relative`

Element stays in normal layout but can be moved relative to its normal position.

### `absolute`

Element can be positioned relative to an appropriate containing block.

### `fixed`

Element stays fixed relative to the viewport.

For example:

```text
           Website
────────────────────────
|                      |
|                      |
|                      |
|              [Chat]  |
|                      |
────────────────────────
```

A fixed element can remain in the same viewport position while the page scrolls.

# 3. Responsive Design

## What is responsive design?

Responsive design means:

> **A website adjusts its layout to different screen sizes.**

For example:

```text
Desktop
┌───────────────────────────────┐
│ Logo   Home  About  Contact   │
├───────────────────────────────┤
│                               │
│       Main Content             │
│                               │
└───────────────────────────────┘
```

On mobile:

```text
┌────────────────┐
│ Logo       ☰   │
├────────────────┤
│                │
│ Main Content   │
│                │
└────────────────┘
```

The same website adapts to:

```text
Desktop
Laptop
Tablet
Mobile
```

---

## Media Queries

CSS uses **media queries** to apply styles depending on screen conditions.

Example:

```css
@media (max-width: 600px) {
    .container {
        display: block;
    }
}
```

Meaning:

> If the screen is 600px or smaller, use this different layout.

---

## Why responsive design matters

Users may access websites using:

```text
📱 Phone
💻 Laptop
🖥️ Desktop
📱 Tablet
```

The website should remain usable on all of them.

# 5. User Experience Basics

**UX = User Experience**

UX means:

> **How easy, clear, comfortable, and understandable a website is for the user.**

CSS plays an important role in UX.

---

## A. Good readability

Text should be easy to read.

Bad:

```text
Tiny text
Poor spacing
Low contrast
```

Better:

```text
Clear text
Good spacing
Good contrast
```

---

## B. Consistent design

Similar elements should look similar.

For example:

```text
[ Login ]
[ Register ]
[ Submit ]
```

Buttons should generally follow a consistent design.

---

## C. Clear navigation

Users should easily understand:

```text
Where am I?
Where can I go?
How do I go back?
What does this button do?
```

---

## D. Visual feedback

When users interact with an element, the interface can show a change.

For example:

```text
Normal:
[ Login ]

Hover:
[ Login ]  ← appearance changes
```

This tells the user that the button is interactive.

---

## E. Mobile usability

Buttons and inputs should be large enough to use comfortably on a phone.

Avoid:

```text
Tiny buttons
Tiny text
Crowded links
Horizontal scrolling
```

```text

 ↓
```

```text
 ↓
JavaScript
 ↓
Browser
 ↓
HTTP/HTTPS
 ↓
Backend/API
 ↓
```

You should especially understand **HTML forms + user input** before moving deeper into JavaScript and HTTP, because that is where user-controlled data begins to enter a web application.
