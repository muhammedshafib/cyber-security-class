# 5. Understand Active Directory Administration 🔐

Active Directory Administration is the process of managing users, groups, permissions, and security settings in a Windows network using Active Directory.

In simple words, it means managing employee accounts, controlling what they can access, and keeping the company network secure.

Let's understand all five topics with simple examples.

## 1. User management

Meaning: User management is the process of creating, modifying, managing, and deleting user accounts in Active Directory.

In simple words, it means managing employee login accounts.

Example:

A company hires a new employee named Rahul.

The IT administrator:

1. Creates a user account for Rahul.
2. Assigns a username and temporary password.
3. Adds him to the appropriate department.
4. Gives him the required permissions.
5. Disables or removes access when he leaves the company.

Common user management activities:

- Create user accounts.
- Reset passwords.
- Unlock locked accounts.
- Modify user details.
- Disable inactive accounts.
- Delete accounts when no longer needed.

Why is it important?

It helps manage employee accounts and prevents unauthorized access.

## 3. Access control

Meaning: Access control is the process of deciding which users can access specific resources and what actions they can perform.

In simple words, it controls who can view, edit, or delete company information.

Example:

A company has a confidential Finance folder.

The administrator configures permissions:

| User             | Access          |
| ---------------- | --------------- |
| Finance Manager  | Full control    |
| Finance Employee | Read and modify |
| HR Employee      | No access       |

### Common access permissions

- Read: View files and folders.
- Write: Create or modify files.
- Modify: Read, write, and delete files.
- Full Control: Manage permissions and perform all permitted actions.

Why is access control important?

- Protects confidential information.
- Prevents unauthorized access.
- Reduces insider threats.
- Helps enforce least privilege.

### Important security configurations

| Configuration          | Purpose                                             |
| ---------------------- | --------------------------------------------------- |
| Strong password policy | Require secure passwords                            |
| Account lockout policy | Lock accounts after repeated failed login attempts  |
| MFA                    | Add another layer of authentication where supported |

Why is security configuration important?

- Prevents unauthorized access.
- Protects user accounts.
- Reduces cyberattack risks.
- Improves network security.

## 5. Administrative practices

Meaning: Administrative practices are the recommended procedures that IT administrators follow to manage Active Directory safely and efficiently.

In simple words, these are the good habits and rules that administrators should follow.

### Important administrative practices

1. Regular backups: Back up Active Directory data to help recover from failures.
2. Monitor user activities: Check login attempts and suspicious activities.
3. Regular access reviews: Remove unnecessary permissions.
4. Disable inactive accounts: Prevent unused accounts from being misused.
5. Use separate admin accounts: Avoid using administrator accounts for normal daily activities.
6. Apply updates: Keep Windows servers updated with security patches.
7. Document changes: Maintain records of important configuration and permission changes.

Example:

An employee leaves the company.

The administrator should:

- Disable the employee's account.
- Revoke access and credentials.
- Remove unnecessary group memberships.
- Review recent account activity.
- Update administrative records.

Why are administrative practices important?

They help maintain a secure, reliable, and well-managed Windows environment.

## 8. Important interview questions

1\. What is user management?

Managing user accounts, passwords, and account permissions in Active Directory.

2\. What is group management?

Organizing users into groups to simplify permission management.

3\. What is access control?

Controlling who can access resources and what actions they can perform.

4\. What is a Security Group?

A group used to assign permissions to multiple users.

5\. Why should inactive accounts be disabled?

Because unused accounts can become targets for attackers and create unnecessary security risks.

6\. What is the purpose of Active Directory backups?

To help restore directory information if data is lost, corrupted, or affected by a system failure or cyberattack.
