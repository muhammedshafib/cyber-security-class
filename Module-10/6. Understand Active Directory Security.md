# 6. Understand Active Directory Security 🔐

Active Directory Security means protecting Active Directory users, computers, accounts, and resources from unauthorized access, cyberattacks, and misuse.

In simple words, it means keeping company accounts safe, protecting passwords, monitoring suspicious activities, and securing the Windows network.

Let's understand all five topics with simple explanations and real-world examples.

## 1. Privileged accounts

Meaning: Privileged accounts are user accounts that have special permissions to perform important administrative tasks in a system or network.

In simple words, these accounts have more power than normal user accounts.

Example:

Imagine a company has three types of users:

| Account              | Permissions                               |
| -------------------- | ----------------------------------------- |
| Normal employee      | Access company files                      |
| IT administrator     | Manage computers and user accounts        |
| Domain Administrator | Manage the entire Active Directory domain |

A Domain Administrator has powerful permissions and can manage users, computers, and security settings across the domain.

### Why are privileged accounts important?

- Manage important system settings.
- Create and delete user accounts.
- Manage permissions.
- Configure security policies.
- Control network resources.

### Security risks

If attackers compromise an administrator account, they may gain control over important company systems.

Best security practices:

1. Give administrator access only to trusted people.
2. Use MFA.
3. Use separate administrator and normal user accounts.
4. Monitor administrator activities.
5. Follow the principle of least privilege.

## 2. Credential security

Meaning: Credential security is the process of protecting login information such as usernames, passwords, authentication tokens, and security keys.

In simple words, it means keeping login details safe from hackers.

[shop.trustico.com](https://shop.trustico.com/blogs/stories/strong-passwords-and-its-importance?utm_source=chatgpt.com)

Example:

An employee uses a password to log in to a company computer.

If an attacker steals that password, they may access the employee's account.

### Common credential attacks

| Attack              | Simple explanation                                                           |
| ------------------- | ---------------------------------------------------------------------------- |
| Brute force         | Trying many passwords until one works                                        |
| Password spraying   | Trying a few common passwords against many accounts                          |
| Phishing            | Tricking users into revealing credentials                                    |
| Credential stuffing | Using stolen username-password combinations from other websites              |
| Pass-the-Hash       | Using stolen password hashes to authenticate in certain Windows environments |

### How to protect credentials

1. Use strong, unique passwords.
2. Enable MFA.
3. Never share passwords.
4. Avoid storing passwords in plain text.
5. Use a password manager.
6. Protect administrator credentials.
7. Use secure authentication methods.

Important: Password hashes are not the same as plaintext passwords, but attackers can still misuse stolen hashes in some circumstances.

## 3. Account monitoring

Meaning: Account monitoring is the process of tracking user login activities and account-related events to identify suspicious or unauthorized behavior.

In simple words, it means watching user accounts to detect unusual activities.

[anavem.com](https://www.anavem.com/en/windows-events/windows-event-id-4625-security-auditing-logon-failure?utm_source=chatgpt.com)

Example:

An employee usually logs in from the company office during working hours.

Suddenly, the same account has:

- Multiple failed login attempts.
- A successful login at an unusual time.
- Access from an unexpected computer.

The security team investigates these activities.

### What should administrators monitor?

- Failed login attempts.
- Successful login attempts.
- Account lockouts.
- New user account creation.
- Changes to administrator privileges.
- Changes to group memberships.
- Password changes.
- Suspicious account activity.

### Important Windows tools

| Tool                  | Purpose                                       |
| --------------------- | --------------------------------------------- |
| Event Viewer          | View Windows security and system logs         |
| Windows Security Logs | Review login and account-related events       |
| PowerShell            | Automate account and security checks          |
| SIEM                  | Collect and analyze security events centrally |

Why is account monitoring important?

- Detects suspicious login attempts.
- Helps identify compromised accounts.
- Provides evidence for security investigations.
- Helps prevent unauthorized access.

## 4. Security baselines

Meaning: A security baseline is a set of recommended security settings and configurations used to protect computers, servers, and networks.

In simple words, it is a standard security checklist that administrators follow to keep systems secure.

[arksoft.work](https://arksoft.work/?utm_source=chatgpt.com)

Example:

A company wants every Windows computer to follow basic security rules.

The administrator establishes a security baseline:

| Security setting     | Recommended configuration         |
| -------------------- | --------------------------------- |
| Password policy      | Require strong passwords          |
| Account lockout      | Configure failed-login limits     |
| Firewall             | Enable Windows Firewall           |
| Guest account        | Disable unnecessary guest access  |
| Windows updates      | Install security patches          |
| Administrator access | Restrict unnecessary privileges   |
| Audit policy         | Enable important security logging |

### Why are security baselines important?

1. Maintain consistent security settings.
2. Reduce system vulnerabilities.
3. Prevent insecure configurations.
4. Improve compliance.
5. Make security auditing easier.

Example tool: Microsoft Security Compliance Toolkit helps administrators assess and apply Microsoft security configuration baselines.

## 5. Attack surface awareness

Meaning: Attack surface refers to all the possible points through which an attacker could try to enter or attack a system.

Attack surface awareness means understanding these possible entry points and reducing unnecessary exposure.

In simple words, it means identifying where hackers might attack your network.

[cymulate.com](https://cymulate.com/cybersecurity-glossary/attack-vector/?utm_source=chatgpt.com)

### Common Active Directory attack surfaces

| Attack surface      | Example                           |
| ------------------- | --------------------------------- |
| User accounts       | Weak employee passwords           |
| Privileged accounts | Too many Domain Administrators    |
| Domain Controllers  | Poorly secured domain servers     |
| Network services    | Unnecessary exposed services      |
| Group Policies      | Incorrect security configurations |
| Endpoints           | Unpatched employee computers      |
| Service accounts    | Overprivileged service accounts   |

### How to reduce the attack surface

1. Disable unused accounts.
2. Remove unnecessary permissions.
3. Secure Domain Controllers.
4. Update Windows systems regularly.
5. Use strong authentication.
6. Monitor suspicious activities.
7. Remove unnecessary services and software.

Real-world example:

A company has 20 administrator accounts, but only 3 people actually need administrative access.

The security team reviews these accounts and removes unnecessary privileges.

This reduces the number of accounts attackers could target for administrative access.

## 6. Real-world cybersecurity scenario

Scenario: An attacker compromises an employee's Active Directory account.

What should the security team do?

1. Privileged accounts: Check whether the compromised account has administrator privileges.
2. Credential security: Reset compromised credentials and revoke affected sessions where appropriate.
3. Account monitoring: Review login records and identify suspicious activities.
4. Security baselines: Check whether the affected systems follow security standards.
5. Attack surface awareness: Identify the weakness that allowed the attacker to enter and reduce similar risks.

This process helps the security team investigate and prevent future attacks.

## 8. Important interview questions

1\. What is a privileged account?

An account with special permissions to manage systems, users, and resources.

2\. What is credential security?

Protecting usernames, passwords, tokens, and other authentication information from unauthorized access.

3\. What is account monitoring?

Tracking user activities and login events to identify suspicious behavior.

4\. What is a security baseline?

A set of recommended security configurations used to protect systems.

5\. What is an attack surface?

All the possible entry points through which an attacker could attempt to compromise a system.

6\. Why are Domain Administrator accounts sensitive?

Because they have extensive control over an Active Directory domain. If compromised, attackers may gain control over many domain resources.
