# 7. Understand Identity Monitoring 🔐

Identity Monitoring is the process of watching user accounts, login activities, and access records to detect unauthorized or suspicious behavior.

In simple words, it means keeping an eye on who logs in, when they log in, what they access, and whether anything looks unusual.

Identity monitoring is one of the main responsibilities of a Security Operations Center (SOC) because it helps detect attacks before they cause major damage.

## 1. Login Events

Meaning: Login events are records created whenever someone tries to log in to a system.

Every login attempt leaves a digital footprint.

### Types of login events

| Event            | Meaning                                  |
| ---------------- | ---------------------------------------- |
| Successful login | User logged in successfully              |
| Failed login     | Login attempt failed                     |
| Logout           | User signed out                          |
| Account lockout  | Account was locked after failed attempts |

### Example

Suppose employee Rahul logs into his office computer.

The system records:

- Username: Rahul
- Time: 9:05 AM
- Computer: Office-PC-12
- Result: Successful login

Later someone enters the wrong password five times.

The system records multiple failed login events.

### Why are login events important?

- Detect unauthorized login attempts.
- Identify brute-force attacks.
- Track user activity.
- Support security investigations.

## 3. Access Monitoring

Meaning: Access monitoring is the process of tracking which resources users access after logging in.

In simple words, it answers:

- What did the user open?
- Which files were accessed?
- What changes were made?

## 4. Suspicious Activities

Meaning: Suspicious activities are actions that look unusual and may indicate a cyberattack or unauthorized access.

They do not always mean an attack is happening, but they should be investigated.

### Common suspicious activities

| Activity                                  | Why it's suspicious           |
| ----------------------------------------- | ----------------------------- |
| Multiple failed logins                    | Possible brute-force attack   |
| Login at midnight                         | Unusual behavior              |
| Login from another country                | Unexpected location           |
| Many password reset attempts              | Possible account attack       |
| Sudden admin privilege change             | Possible privilege escalation |
| Access to confidential files unexpectedly | Possible insider threat       |

### Real-world example

An employee normally logs in from Kerala.

Suddenly the account appears to log in from another country.

The SOC investigates whether:

- The employee is actually traveling.
- The account was compromised.
- Additional verification is needed.

### Common attack indicators

- Brute-force attacks
- Password spraying
- Phishing compromise
- Privilege escalation
- Unusual administrator activity
- Excessive file downloads

Meaning: A SOC (Security Operations Center) follows a structured process to investigate suspicious identity-related activities.

### The 7-step SOC investigation workflow

1\. Alert received

The SIEM or monitoring system detects suspicious activity.

2\. Verify the alert

Check whether it is a real threat or a false alarm.

3\. Collect evidence

Gather authentication logs, login events, and system records.

4\. Analyze the incident

Determine how the suspicious activity happened.

5\. Contain the threat

Disable the affected account or block malicious access.

6\. Recover

Restore normal operations after securing the account.

7\. Document the incident

Record what happened and recommend improvements.

### Example investigation

Alert: 20 failed login attempts on an administrator account.

The SOC team:

1. Reviews authentication logs.
2. Checks the source IP.
3. Confirms it is a brute-force attempt.
4. Locks the account temporarily.
5. Resets credentials.
6. Enables additional protections if needed.
7. Documents the incident.

# Important Interview Questions

1\. What is identity monitoring?

Identity monitoring is the process of tracking user logins, authentication events, and resource access to detect suspicious activities.

2\. What is the difference between login events and authentication logs?

- Login events record login attempts.
- Authentication logs provide detailed information about how authentication occurred.

3\. Name three suspicious activities.

- Multiple failed login attempts.
- Login from an unusual location.
- Unexpected administrator privilege changes.

4\. What is the first step in a SOC investigation?

The first step is receiving and verifying a security alert.

5\. Which Windows tool is commonly used to view authentication logs?

Event Viewer.
