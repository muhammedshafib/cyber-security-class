# 2. Understand Linux Command Line

The **Linux Command Line** is one of the most important skills for Linux administration and cybersecurity.

A command line allows you to interact with Linux by typing commands instead of using a graphical interface.

```text
User
  ↓
Terminal
  ↓
Shell (Bash/Zsh)
  ↓
Linux Kernel
  ↓
System
```

For cybersecurity, you should be comfortable with **navigation, file management, text processing, searching, and administrative commands**.

---

# A. Navigation Commands

Navigation means **moving around the Linux filesystem and understanding where you are**.

## 1. `pwd`

**PWD = Print Working Directory**

Shows your current location.

```bash
pwd
```

Example:

```text
/home/shafi
```

Meaning:

> You are currently inside `/home/shafi`.

### Malayalam

`pwd` ഇപ്പോൾ നിങ്ങൾ ഏത് directory-ൽ ആണെന്ന് കാണിക്കുന്നു.

---

## 2. `ls`

Lists files and directories.

```bash
ls
```

Example:

```text
Documents  Downloads  Pictures  test.txt
```

### Useful options

```bash
ls -l
```

Detailed listing.

```bash
ls -a
```

Shows hidden files.

```bash
ls -la
```

Detailed listing including hidden files.

```bash
ls -lh
```

Human-readable file sizes.

### Important

```text
-l → long/detailed listing
-a → all, including hidden
-h → human-readable sizes
```

---

# 3. `cd`

**CD = Change Directory**

Used to move between directories.

```bash
cd Documents
```

Move into Documents.

Go back one level:

```bash
cd ..
```

Go to your home directory:

```bash
cd ~
```

Go to the root filesystem:

```bash
cd /
```

Go to the previous directory:

```bash
cd -
```

---

## Example

Suppose:

```text
/home/shafi
       |
       +--- Documents
       |
       +--- Downloads
```

You can do:

```bash
pwd
cd Documents
pwd
cd ..
pwd
```

---

# 4. Absolute vs Relative Path

This is very important.

### Absolute path

Starts from `/`.

Example:

```bash
cd /home/shafi/Documents
```

It gives the complete location.

### Relative path

Starts from your current location.

```bash
cd Documents
```

If you're already in `/home/shafi`, this means:

```text
/home/shafi/Documents
```

---

# B. File Management

File management means:

* Creating files
* Creating directories
* Copying
* Moving
* Renaming
* Deleting
* Reading files

---

# 1. `touch`

Creates an empty file or updates its timestamp.

```bash
touch test.txt
```

Check:

```bash
ls
```

You should see:

```text
test.txt
```

---

# 2. `mkdir`

**MKDIR = Make Directory**

Creates a directory.

```bash
mkdir cybersecurity
```

Create multiple directories:

```bash
mkdir linux network security
```

Create nested directories:

```bash
mkdir -p project/logs/2026
```

---

# 3. `cp`

**CP = Copy**

Copy a file:

```bash
cp test.txt backup.txt
```

Copy a directory:

```bash
cp -r project backup
```

`-r` means recursive.

---

# 4. `mv`

**MV = Move**

Move a file:

```bash
mv test.txt Documents/
```

It is also commonly used to rename files:

```bash
mv old.txt new.txt
```

---

# 5. `rm`

**RM = Remove**

Delete a file:

```bash
rm test.txt
```

Delete a directory and its contents:

```bash
rm -r project
```

### ⚠️ Important

Be extremely careful with:

```bash
rm -rf
```

`rm` generally does not provide a normal recycle-bin experience. A mistaken command can delete important files.

Never run destructive commands such as:

```bash
rm -rf /
```

or similar commands on a real system.

---

# 6. `cat`

Displays file contents.

```bash
cat test.txt
```

Example:

```text
Hello Linux
```

It can also combine files:

```bash
cat file1.txt file2.txt
```

---

# 7. `less`

Useful for reading large files.

```bash
less /var/log/syslog
```

You can scroll through the file without dumping everything onto the terminal at once.

Press:

```text
q
```

to quit.

---

# 8. `head`

Shows the beginning of a file.

```bash
head test.txt
```

Show first 20 lines:

```bash
head -n 20 test.txt
```

---

# 9. `tail`

Shows the end of a file.

```bash
tail test.txt
```

Very useful for logs.

For example:

```bash
tail -f /var/log/syslog
```

`-f` follows the file as new data is added.

This is useful for monitoring logs in real time.

---

# C. Text Processing

Linux provides powerful commands for manipulating and analyzing text.

These are especially important for cybersecurity because logs and configuration files are usually text-based.

---

# 1. `grep`

**GREP = Global Regular Expression Print**

Used to search text for matching patterns.

Example:

```bash
grep "error" log.txt
```

Finds lines containing `error`.

Case-insensitive:

```bash
grep -i "error" log.txt
```

Show line numbers:

```bash
grep -n "error" log.txt
```

Search recursively:

```bash
grep -r "password" /etc/
```

⚠️ Be careful when searching sensitive directories and files; access permissions and privacy matter.

---

# 2. Pipe `|`

The pipe sends the output of one command into another command.

Example:

```bash
ps aux | grep ssh
```

Flow:

```text
ps aux
   ↓
All processes
   ↓
grep ssh
   ↓
Matching processes
```

This is one of the most important Linux concepts.

---

# 3. `sort`

Sorts lines.

```bash
sort names.txt
```

Reverse order:

```bash
sort -r names.txt
```

---

# 4. `uniq`

Removes adjacent duplicate lines.

```bash
sort names.txt | uniq
```

Count occurrences:

```bash
sort names.txt | uniq -c
```

---

# 5. `wc`

**WC = Word Count**

Example:

```bash
wc file.txt
```

It can show:

```text
lines words bytes
```

Count lines:

```bash
wc -l file.txt
```

Count words:

```bash
wc -w file.txt
```

---

# 6. `cut`

Extracts sections/columns from text.

Example:

```bash
cut -d: -f1 /etc/passwd
```

Here:

```text
-d: → delimiter is :
-f1 → select first field
```

This can display usernames from `/etc/passwd`.

---

# 7. `awk`

`awk` is a powerful text-processing language/tool.

Example:

```bash
awk '{print $1}' file.txt
```

It prints the first whitespace-separated field from each line.

A common log-analysis pattern is:

```bash
awk '{print $1}' access.log
```

which might extract the first field, depending on the log format.

---

# 8. `sed`

**SED = Stream Editor**

Used for processing and transforming text.

Example:

```bash
sed 's/old/new/g' file.txt
```

This replaces occurrences of `old` with `new` in the output.

---

# 9. Redirection

### `>`

Redirect output to a file and overwrite it.

```bash
ls > files.txt
```

### `>>`

Append output.

```bash
date >> log.txt
```

### `<`

Use a file as input.

```bash
sort < names.txt
```

---

# D. Search Operations

Search operations are extremely important in Linux administration and cybersecurity.

---

# 1. `find`

Search for files/directories based on conditions.

Example:

```bash
find /home -name "test.txt"
```

Find `.log` files:

```bash
find /var/log -name "*.log"
```

Find directories:

```bash
find /home -type d -name "Downloads"
```

Find files modified recently:

```bash
find /home -type f -mtime -1
```

---

# 2. `locate`

Searches a pre-built file database.

```bash
locate test.txt
```

It can be faster than `find`, but results depend on the database being up to date.

On some systems you may need to install/configure the locate database first.

---

# 3. `which`

Shows which executable will be used for a command.

```bash
which python
```

Example:

```text
/usr/bin/python
```

---

# 4. `whereis`

Searches for binaries, source files, and manual pages associated with a command.

```bash
whereis bash
```

---

# 5. `grep` + `find`

You can combine commands.

For example:

```bash
find /var/log -type f -name "*.log"
```

Then search inside files with appropriate permissions:

```bash
grep -R "failed" /var/log
```

This is useful when investigating logs.

---

# E. Administrative Commands

Administrative commands allow you to manage the Linux system.

Many require elevated privileges.

---

# 1. `sudo`

**SUDO = Superuser Do**

Allows an authorized user to run a command with elevated privileges.

Example:

```bash
sudo systemctl restart ssh
```

Another example:

```bash
sudo apt update
```

`sudo` does not automatically mean "become root permanently"; it normally elevates privileges for a particular command.

---

# 2. `su`

**SU = Substitute User**

Switches to another user account.

```bash
su username
```

On systems where root login is configured:

```bash
su -
```

may start a root login shell.

`sudo` is generally preferred for controlled administrative actions.

---

# 3. `apt`

On Debian/Ubuntu-based systems, `apt` is a package management tool.

Update package information:

```bash
sudo apt update
```

Upgrade installed packages:

```bash
sudo apt upgrade
```

Install a package:

```bash
sudo apt install nginx
```

Remove a package:

```bash
sudo apt remove nginx
```

Other Linux distributions use different package managers, such as `dnf`, `yum`, `pacman`, or `zypper`.

---

# 4. `systemctl`

Used to manage systemd services.

Check a service:

```bash
systemctl status ssh
```

Start:

```bash
sudo systemctl start ssh
```

Stop:

```bash
sudo systemctl stop ssh
```

Restart:

```bash
sudo systemctl restart ssh
```

Enable at boot:

```bash
sudo systemctl enable ssh
```

---

# 5. `ps`

Shows processes.

```bash
ps aux
```

Useful for checking:

* PID
* User
* CPU usage
* Memory usage
* Running commands

---

# 6. `kill`

Sends a signal to a process.

```bash
kill PID
```

Example:

```bash
kill 1234
```

The normal `kill` command sends `SIGTERM`, requesting the process to terminate gracefully.

---

# 7. `df`

Shows filesystem disk usage.

```bash
df -h
```

Example:

```text
Filesystem      Size  Used Avail Use%
/dev/nvme0n1p2  100G   40G   60G  40%
```

`-h` means human-readable.

---

# 8. `du`

Shows how much space files/directories consume.

```bash
du -sh Documents
```

Example:

```text
5.2G    Documents
```

---

# 9. `free`

Shows memory/RAM usage.

```bash
free -h
```

---

# 10. `uname`

Displays system/kernel information.

```bash
uname -a
```

---

# 11. `hostname`

Displays the system hostname.

```bash
hostname
```

---

# 12. `ip`

Used for network configuration and information.

Show interfaces and addresses:

```bash
ip addr
```

Show routing table:

```bash
ip route
```

---

# 13. `ss`

Shows network sockets/connections.

For listening TCP/UDP sockets:

```bash
ss -tuln
```

This is particularly useful in security investigations because it can help identify which ports are listening.

---

# 🔥 Important Cybersecurity Command-Line Flow

As a cybersecurity beginner, think like this:

```text
                    Linux CLI
                        |
        +---------------+---------------+
        |               |               |
    Navigation       Files          Processes
        |               |               |
     pwd/ls/cd       cp/mv/rm        ps/kill
        |               |               |
        +---------------+---------------+
                        |
                  Text & Search
                        |
              grep/find/awk/sed
                        |
                   Administration
                        |
          sudo/systemctl/apt
                        |
                 Security Analysis
```

## Interview Answer

If asked **"What is the Linux command line?"**, answer:

> **The Linux command line is a text-based interface through which users interact with the Linux operating system using commands. It allows users to navigate the filesystem, manage files, process text, search for information, manage processes and services, and perform administrative tasks.**

For cybersecurity, your next important step after these commands is to learn **Linux permissions (`rwx`), ownership, `chmod`, `chown`, `umask`, and special permissions (`SUID`, `SGID`, sticky bit)** because these are heavily used in Linux security.
