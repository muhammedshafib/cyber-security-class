# 3. Understand User & Permission Management — Linux

User and permission management is an important Linux administration and cybersecurity topic. It controls **who can access the system, what they can access, and what actions they can perform**.

---

## a. User Accounts

A **user account** represents a person or service that can log in to and use a Linux system.

### Important user commands

| Command      | Usage                                 | Example                           |
| ------------ | ------------------------------------- | --------------------------------- |
| `whoami`     | Shows current username                | `whoami`                          |
| `id`         | Shows user ID and groups              | `id`                              |
| `who`        | Shows logged-in users                 | `who`                             |
| `w`          | Shows logged-in users and activity    | `w`                               |
| `sudo`       | Runs command with elevated privileges | `sudo apt update`                 |
| `adduser`    | Creates a user                        | `sudo adduser shafi`              |
| `useradd`    | Creates a user                        | `sudo useradd shafi`              |
| `passwd`     | Changes password                      | `sudo passwd shafi`               |
| `usermod`    | Modifies a user                       | `sudo usermod -s /bin/bash shafi` |
| `userdel`    | Deletes a user                        | `sudo userdel shafi`              |
| `userdel -r` | Deletes user and home directory       | `sudo userdel -r shafi`           |

### Create a user

```bash
sudo adduser shafi
```

You will normally be asked for:

```text
New password:
Retype new password:
Full Name:
Room Number:
Work Phone:
Home Phone:
Other:
```

### Check the user

```bash
id shafi
```

Example:

```text
uid=1001(shafi) gid=1001(shafi) groups=1001(shafi)
```

### Change password

```bash
sudo passwd shafi
```

### Delete user

```bash
sudo userdel shafi
```

Delete the user **and their home directory**:

```bash
sudo userdel -r shafi
```

⚠️ Be careful with `userdel -r` because it removes the user's home-directory data.

---

# b. Groups

A **group** is a collection of users.

Groups make permission management easier. Instead of giving permissions to users individually, you can give permissions to a group.

### Important group commands

| Command       | Usage                        |
| ------------- | ---------------------------- |
| `groups`      | Shows groups of current user |
| `id`          | Shows UID, GID and groups    |
| `groupadd`    | Creates a group              |
| `groupdel`    | Deletes a group              |
| `usermod -aG` | Adds user to a group         |
| `gpasswd -d`  | Removes user from a group    |

### Create a group

```bash
sudo groupadd developers
```

### Add a user to a group

```bash
sudo usermod -aG developers shafi
```

**Important:** Use `-aG`, not just `-G`.

`-a` = append
`-G` = supplementary group

### Check groups

```bash
groups shafi
```

or:

```bash
id shafi
```

### Remove user from group

```bash
sudo gpasswd -d shafi developers
```

### Delete a group

```bash
sudo groupdel developers
```

# c. File Permissions

Linux uses permissions to control access to files and directories.

Run:

```bash
ls -l
```

Example:

```text
-rwxr-xr-- 1 shafi developers 1200 Aug 17 test.sh
```

The first section:

```text
-rwxr-xr--
```

can be divided into:

```text
- | rwx | r-x | r--
  |     |     |
  |     |     └── Others
  |     └──────── Group
  └────────────── Owner
```

### Permission types

| Symbol | Meaning       | Numeric value |
| ------ | ------------- | ------------: |
| `r`    | Read          |             4 |
| `w`    | Write         |             2 |
| `x`    | Execute       |             1 |
| `-`    | No permission |             0 |

### Example

```text
rwx
```

Calculation:

```text
r = 4
w = 2
x = 1

4 + 2 + 1 = 7
```

Therefore:

```text
rwx = 7
r-x = 5
r-- = 4
```

So:

```text
rwxr-xr--
```

means:

```text
Owner  = 7
Group  = 5
Others = 4
```

Therefore the numeric permission is:

```text
754
```

---

## chmod

`chmod` changes file permissions.

### Numeric method

```bash
chmod 755 script.sh
```

This means:

```text
Owner  = rwx
Group  = r-x
Others = r-x
```

Another example:

```bash
chmod 644 file.txt
```

means:

```text
Owner  = rw-
Group  = r--
Others = r--
```

### Symbolic method

Give owner execute permission:

```bash
chmod u+x script.sh
```

Give group write permission:

```bash
chmod g+w file.txt
```

Remove others' write permission:

```bash
chmod o-w file.txt
```

Give everyone read permission:

```bash
chmod a+r file.txt
```

Where:

```text
u = user/owner
g = group
o = others
a = all
```

### Recursive permissions

For a directory and everything inside it:

```bash
chmod -R 755 myfolder
```

⚠️ Use recursive permission changes carefully.

---

# d. Ownership

Linux files have an **owner** and a **group owner**.

Check ownership:

```bash
ls -l
```

Example:

```text
-rw-r--r-- 1 shafi developers 500 file.txt
```

Here:

```text
Owner = shafi
Group = developers
```

---

## chown

`chown` changes ownership.

### Change owner

```bash
sudo chown shafi file.txt
```

### Change owner and group

```bash
sudo chown shafi:developers file.txt
```

### Change group only

```bash
sudo chgrp developers file.txt
```

### Recursive ownership

```bash
sudo chown -R shafi:developers myfolder
```

# e. Privilege Management

**Privilege management** controls which users can perform administrative operations.

The most important Linux privilege mechanisms are:

* `sudo`
* `su`
* Root account
* Sudo groups
* `/etc/sudoers`

---

## sudo

`sudo` allows an authorized user to execute a command with elevated privileges.

Example:

```bash
sudo apt update
```

Install software:

```bash
sudo apt install nginx
```

Change a system file:

```bash
sudo nano /etc/hosts
```

### Check sudo access

```bash
sudo -l
```

This shows commands the current user is allowed to run with `sudo`.

---

## su

`su` switches to another user.

Switch to root:

```bash
su -
```

Switch to another user:

```bash
su - shafi
```

You will generally need the target user's password.

---

# Root User

`root` is the Linux superuser.

Root can generally:

* Create/delete users
* Change permissions
* Modify system files
* Install software
* Stop/start services
* Change ownership
* Configure the system

Check current user:

```bash
whoami
```

Check UID:

```bash
id
```

Root normally has:

```text
UID = 0
```

⚠️ Avoid using a root shell unnecessarily. A wrong command executed as root can damage the system.

---

# Important Configuration Files

Linux stores important account and authentication information in several files.

### `/etc/passwd`

Contains basic user account information.

```bash
cat /etc/passwd
```

Example structure:

```text
username:x:UID:GID:description:home:shell
```

### `/etc/group`

Contains group information.

```bash
cat /etc/group
```

### `/etc/shadow`

Contains password hashes and password-related information.

```bash
sudo cat /etc/shadow
```

⚠️ Do not modify these files manually unless you understand exactly what you are doing.

# Practical Example

Suppose you want to create a development environment.

### Step 1 — Create user

```bash
sudo adduser developer
```

### Step 2 — Create group

```bash
sudo groupadd developers
```

### Step 3 — Add user to group

```bash
sudo usermod -aG developers developer
```

### Step 4 — Create a project directory

```bash
sudo mkdir /opt/project
```

### Step 5 — Change ownership

```bash
sudo chown -R developer:developers /opt/project
```

### Step 6 — Set permissions

```bash
sudo chmod -R 770 /opt/project
```

Now:

```text
Owner  = read + write + execute
Group  = read + write + execute
Others = no access
```

Because:

```text
7 = rwx
7 = rwx
0 = ---
```

So:

```text
770 = rwxrwx---
```
