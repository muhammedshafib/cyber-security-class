# 7. Understand Security Automation with Bash

**Security automation with Bash** means using Bash scripts to automatically perform common cybersecurity tasks instead of doing everything manually.

For example, a security administrator can write a Bash script that:

* Reads and analyzes logs
* Checks user accounts
* Monitors CPU, RAM, and disk usage
* Detects suspicious activity
* Generates security reports
* Performs routine administration tasks

---

## a. Log Parsing

### What is log parsing?

**Log parsing** means reading system logs and extracting useful information from them.

Linux systems generate logs for:

* User login/logout
* Failed authentication
* Services starting/stopping
* System errors
* Network activity
* Security events

Common logs include:

```bash
/var/log/auth.log
/var/log/syslog
```

On systems using `systemd`, you can also use:

```bash
journalctl
```

### Example: Find failed login attempts

```bash
grep "Failed password" /var/log/auth.log
```

This searches the authentication log for failed password attempts.

### Count failed login attempts

```bash
grep "Failed password" /var/log/auth.log | wc -l
```

**How it works:**

```text
grep
 ↓
Find "Failed password"
 ↓
auth.log
 ↓
wc -l
 ↓
Count matching lines
```

### Using journalctl

```bash
journalctl | grep "Failed"
```

Only authentication-related messages can also be investigated with:

```bash
journalctl -u ssh
```

or on some systems:

```bash
journalctl -u ssh.service
```

### Why log parsing is useful

It can help detect:

* Repeated failed logins
* Suspicious authentication activity
* Service failures
* Unexpected system errors
* Possible brute-force attempts

# b. User Auditing

### What is user auditing?

**User auditing** means checking Linux user accounts and their activities to identify unauthorized or suspicious accounts.

Important information includes:

* Existing users
* Logged-in users
* User IDs
* Groups
* Login history
* Failed login attempts
* Privileges

### List users

```bash
cat /etc/passwd
```

A simpler list of usernames:

```bash
cut -d: -f1 /etc/passwd
```

### Find currently logged-in users

```bash
who
```

Another useful command:

```bash
w
```

### Check your current user

```bash
whoami
```

### Check user ID and groups

```bash
id username
```

Example:

```bash
id shafi
```

### Check login history

```bash
last
```

### Check failed logins

```bash
lastb
```

> `lastb` may require administrator privileges.

### Security auditing example

```bash
#!/bin/bash

echo "===== USER AUDIT ====="

echo "Current User:"
whoami

echo
echo "Logged-in Users:"
who

echo
echo "User Accounts:"
cut -d: -f1 /etc/passwd

echo
echo "Recent Logins:"
last | head
```

This script automatically collects basic user information.

# c. System Monitoring

### What is system monitoring?

**System monitoring** means continuously checking the health and activity of a Linux system.

Security administrators commonly monitor:

* CPU usage
* RAM usage
* Disk usage
* Running processes
* Network connections
* Services
* System uptime

### Check CPU and processes

```bash
top
```

Another useful command:

```bash
ps aux
```

### Check memory

```bash
free -h
```

Example output may show:

```text
              total   used   free
Mem:           7.7G   3.2G   2.1G
Swap:          2.0G   0.0G   2.0G
```

### Check disk usage

```bash
df -h
```

### Check a directory's size

```bash
du -sh /var/log
```

### Check system uptime

```bash
uptime
```

### Check services

```bash
systemctl --type=service
```

Check a particular service:

```bash
systemctl status ssh
```

### Check failed services

```bash
systemctl --failed
```

This is useful for quickly identifying services that have failed.

# d. Automated Reporting

### What is automated reporting?

**Automated reporting** means creating a report automatically using a Bash script.

Instead of manually checking:

```text
CPU
RAM
Disk
Users
Services
Logs
```

a script can collect all of them and place the information into one report.

### Example security report script

```bash
#!/bin/bash

REPORT="security_report.txt"

echo "===== SECURITY REPORT =====" > "$REPORT"
echo "Date: $(date)" >> "$REPORT"

echo >> "$REPORT"
echo "===== CURRENT USER =====" >> "$REPORT"
whoami >> "$REPORT"

echo >> "$REPORT"
echo "===== LOGGED-IN USERS =====" >> "$REPORT"
who >> "$REPORT"

echo >> "$REPORT"
echo "===== MEMORY =====" >> "$REPORT"
free -h >> "$REPORT"

echo >> "$REPORT"
echo "===== DISK =====" >> "$REPORT"
df -h >> "$REPORT"

echo >> "$REPORT"
echo "===== FAILED SERVICES =====" >> "$REPORT"
systemctl --failed >> "$REPORT"

echo >> "$REPORT"
echo "===== RECENT LOGINS =====" >> "$REPORT"
last | head >> "$REPORT"

echo "Report created: $REPORT"
```

Run it:

```bash
chmod +x security_report.sh
./security_report.sh
```

The result will be saved as:

```text
security_report.txt
```

### Why automated reporting is useful

It:

* Saves time
* Reduces repetitive work
* Creates consistent reports
* Helps with system auditing
* Makes security monitoring easier
* Provides evidence for investigation

# e. Security Administration Tasks

### What are security administration tasks?

These are routine tasks performed by administrators to maintain system security.

Examples include:

* Creating users
* Removing users
* Managing groups
* Changing passwords
* Managing permissions
* Checking services
* Checking logs
* Updating systems
* Monitoring suspicious activity

### Create a user

```bash
sudo useradd username
```

Better interactive method:

```bash
sudo adduser username
```

### Change password

```bash
sudo passwd username
```

### Add user to a group

```bash
sudo usermod -aG groupname username
```

Example:

```bash
sudo usermod -aG sudo shafi
```

### Lock an account

```bash
sudo usermod -L username
```

### Unlock an account

```bash
sudo usermod -U username
```

### Delete a user

```bash
sudo userdel username
```

To remove the user's home directory too:

```bash
sudo userdel -r username
```

**Be careful with this command because it can permanently remove the user's files.**

# Complete Security Automation Example

A simple Bash security-monitoring script could combine all five areas:

```bash
#!/bin/bash

echo "================================"
echo "     LINUX SECURITY CHECK"
echo "================================"

echo
echo "[1] Current User"
whoami

echo
echo "[2] Logged-in Users"
who

echo
echo "[3] Memory Usage"
free -h

echo
echo "[4] Disk Usage"
df -h

echo
echo "[5] Failed Services"
systemctl --failed

echo
echo "[6] Recent Failed Logins"
grep "Failed password" /var/log/auth.log | tail -10

echo
echo "[7] Recent Login History"
last | head -10

echo
echo "================================"
echo "       CHECK COMPLETE"
echo "================================"
```

### Overall workflow

```text
Bash Script
     |
     +----> Log Parsing
     |          |
     |          +--> Find suspicious events
     |
     +----> User Auditing
     |          |
     |          +--> Check users and logins
     |
     +----> System Monitoring
     |          |
     |          +--> CPU / RAM / Disk / Services
     |
     +----> Automated Reporting
     |          |
     |          +--> Save results
     |
     +----> Security Administration
                |
                +--> Manage users, groups, permissions
```

### മലയാളത്തിൽ ചുരുക്കത്തിൽ

**Bash Security Automation** എന്നത് Linux security-related ജോലികൾ Bash script ഉപയോഗിച്ച് **automatic ആയി ചെയ്യുന്നതാണ്**.

* **Log Parsing** → logs പരിശോധിച്ച് suspicious activity കണ്ടെത്തുക.
* **User Auditing** → users, groups, login history എന്നിവ പരിശോധിക്കുക.
* **System Monitoring** → CPU, RAM, disk, processes, services എന്നിവ monitor ചെയ്യുക.
* **Automated Reporting** → ഈ വിവരങ്ങൾ script ഉപയോഗിച്ച് ഒരു report ആക്കുക.
* **Security Administration** → users, passwords, groups, permissions, services തുടങ്ങിയവ manage ചെയ്യുക.

**Simple idea:**
`Bash Script → Collect Information → Analyze → Detect Problems → Generate Report → Take Administrative Action`
