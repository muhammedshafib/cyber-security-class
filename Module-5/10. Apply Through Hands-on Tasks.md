## Project 1 — File Hash Utility

A hash can be used to check whether a file's contents have changed.

### Project structure

```text
file_hash_tool/
│
├── main.py
└── test.txt
```

### `main.py`

```python
import hashlib


def calculate_sha256(filename):
    sha256 = hashlib.sha256()

    with open(filename, "rb") as file:
        while chunk := file.read(4096):
            sha256.update(chunk)

    return sha256.hexdigest()


filename = input("Enter filename: ")

try:
    file_hash = calculate_sha256(filename)
    print("SHA-256:", file_hash)

except FileNotFoundError:
    print("File not found.")
```

---

## Let's understand the workflow

```text
User enters filename
        ↓
calculate_sha256()
        ↓
Open file
        ↓
Read file in chunks
        ↓
Calculate SHA-256
        ↓
Return hash
        ↓
Display hash
```

### Important concepts used

This one project combines:

   +

## Project 2 — Security Log Analyzer

Structure:

```text
log_analyzer/
│
├── main.py
└── security.log
```

### `security.log`

```text
Failed login from 192.168.1.20
Successful login from 192.168.1.10
Failed login from 192.168.1.20
Failed login from 192.168.1.20
Failed login from 10.0.0.5
```

### `main.py`

```python
from collections import Counter
failed=[]
with open("new4.log","r") as file:
    for line in file:
        if "Failed login" in line:
            ip=line.split()[-1]
            failed.append(ip)
count=Counter(failed)
for ip,count in count.items():
    print(ip,"-->",count,"failed logi")
```

---

## What is happening?

The program reads:

```text
192.168.1.20 → 3 failed attempts
10.0.0.5 → 1 failed attempts
```

# Project 3 — JSON Security Analyzer

Structure:

```text
json_analyzer/
│
├── main.py
└── users.json
```

### `users.json`

```json
[
    {
        "username": "alice",
        "status": "success"
    },
    {
        "username": "bob",
        "status": "failed"
    },
    {
        "username": "admin",
        "status": "failed"
    }
]
```

### `main.py`

```python
import json


try:
    with open("users.json", "r") as file:
        data = json.load(file)

    for record in data:
        username = record["username"]
        status = record["status"]

        print(username, "->", status)

except FileNotFoundError:
    print("JSON file not found.")

except json.JSONDecodeError:
    print("Invalid JSON file.")
```

---

## The important line

```python
data = json.load(file)
```

This converts JSON into Python objects.

Conceptually:

```text
JSON
 ↓
json.load()
 ↓
Python list/dictionaries
```

So this JSON:

```json
{
    "username": "alice",
    "status": "success"
}
```

becomes approximately:

```python
{
    "username": "alice",
    "status": "success"
}
```

Now you can use:

```python
record["username"]
```

and:

```python
record["status"]
```

# 4. Create Reusable Scripts

Now we move from individual scripts to **reusable tools**.

Instead of putting everything into:

```text
main.py
```

we divide the project into modules.

For example:

```text
security_toolkit/
│
├── main.py
│
└── security/
    ├── __init__.py
    ├── hash_utils.py
    ├── log_utils.py
    └── json_utils.py
```

---

## `hash_utils.py`

```python
import hashlib


def calculate_sha256(filename):
    sha256 = hashlib.sha256()

    with open(filename, "rb") as file:
        while chunk := file.read(4096):
            sha256.update(chunk)

    return sha256.hexdigest()
```

---

## `log_utils.py`

```python
from collections import Counter


def count_events(filename):
    counter = Counter()

    with open(filename, "r") as file:
        for line in file:
            parts = line.split()

            if parts:
                counter[parts[0]] += 1

    return counter
```

---

## `main.py`

```python
from security.hash_utils import calculate_sha256
from security.log_utils import count_events
```

Now `main.py` can reuse functions from other files.

This is much better than copying the same code into every program.

# 5. Why Reusable Code Matters

Imagine you have five projects.

Without reusable modules:

```text
Project 1 → hash code
Project 2 → copied hash code
Project 3 → copied hash code
Project 4 → copied hash code
Project 5 → copied hash code
```

If you discover a bug, you have to fix it five times.

With reusable modules:

```text
             hash_utils.py
             /    |    \
            ↓     ↓     ↓
       Project 1  2     3
```

You maintain one piece of code.

This is one of the main reasons we learned **modules and functions** earlier.

# 6. Automate Simple Security Workflows

Now we combine everything.

Suppose you want a program that:

1. Reads a security log.
2. Counts failed logins.
3. Creates a report.
4. Saves the report as JSON.

That's a simple security automation workflow.

---

# Project 4 — Security Report Generator

Structure:

```text
security_report/
│
├── main.py
├── security.log
└── report.json
```

### `security.log`

```text
SUCCESS alice
FAILED bob
FAILED admin
SUCCESS john
FAILED bob
```

### `main.py`

```python
import json
from collections import Counter


def analyze_log(filename):
    counter = Counter()

    with open(filename, "r") as file:
        for line in file:
            parts = line.split()

            if parts:
                counter[parts[0]] += 1

    return counter


try:
    results = analyze_log("security.log")

    report = {
        "total_events": sum(results.values()),
        "successful_logins": results["SUCCESS"],
        "failed_logins": results["FAILED"]
    }

    with open("report.json", "w") as file:
        json.dump(report, file, indent=4)

    print("Security report created.")

except FileNotFoundError:
    print("Security log not found.")
```

---

# 7. What Happens Internally?

The complete workflow is:

```text
security.log
     ↓
open()
     ↓
Read each line
     ↓
split()
     ↓
Count events
     ↓
Counter
     ↓
Create dictionary
     ↓
json.dump()
     ↓
report.json
```

The generated JSON might look like:

```json
{
    "total_events": 5,
    "successful_logins": 2,
    "failed_logins": 3
}
```

Now you have automated a small security-analysis workflow.

# 11. Your Hands-on Development Cycle

For every project, follow this process:

## Step 1 — Define the problem

Example:

> I want to count failed login attempts in a log file.

## Step 2 — Design the solution

```text
Read file
 ↓
Read lines
 ↓
Find FAILED
 ↓
Count
 ↓
Display result
```

## Step 3 — Write small code

Don't write 500 lines at once.

Start with:

```python
with open("security.log", "r") as file:
    for line in file:
        print(line)
```

First make sure that works.

## Step 4 — Add functionality

Then:

```python
if "FAILED" in line:
    print("Failed login detected")
```

Then count them.

## Step 5 — Add error handling

```python
try:
    ...
except FileNotFoundError:
    ...
```

## Step 6 — Test

Try:

```text
Normal file
Empty file
Missing file
Malformed data
Unexpected input
Large file
```

## Step 7 — Security review

Ask:

```text
Can input be abused?

Can files outside the intended directory be accessed?

Are secrets exposed?

Are commands executed?

Is user input passed to subprocess?

Are errors handled safely?
```

## Step 8 — Refactor

Move reusable functionality into modules.
