# 4. Understand Functions in Python

Functions are one of the **most important topics in Python**. They help you write code once and **reuse it many times**.

For cybersecurity, functions are especially useful for things like:

* Checking IP addresses
* Validating passwords
* Checking ports
* Analyzing logs
* User auditing
* Security automation

---

## 1. Function Creation

### What is a function?

A **function** is a reusable block of code that performs a specific task.

### Basic syntax

```python
def function_name():
    # code
```

* `def` → tells Python you are creating a function
* `function_name` → name of the function
* `()` → parameters go here
* `:` → starts the function body
* Indentation → code belonging to the function

### Example

```python
def greet():
    print("Hello, Shafi!")

greet()
```

### Output

```text
Hello, Shafi!
```

Here:

```python
def greet():
```

creates the function.

And:

```python
greet()
```

calls/runs the function.

### Function can be called multiple times

```python
def greet():
    print("Hello!")

greet()
greet()
greet()
```

Output:

```text
Hello!
Hello!
Hello!
```

**Important:** A function does not normally execute when you define it. It executes when you **call it**.

# 2. Parameters

A **parameter** allows us to send information into a function.

### Example

```python
def greet(name):
    print(f"Hello, {name}!")

greet("Shafi")
greet("Rahul")
```

Output:

```text
Hello, Shafi!
Hello, Rahul!
```

Here:

```python
name
```

is the **parameter**.

And:

```python
"Shafi"
```

is the **argument** passed to the function.

### Parameter vs Argument

```python
def greet(name):      # name = parameter
    print(name)

greet("Shafi")        # "Shafi" = argument
```

---

## Multiple Parameters

```python
def add_numbers(a, b):
    print(a + b)

add_numbers(10, 20)
```

Output:

```text
30
```

Another example:

```python
def student_info(name, age, city):
    print(f"Name: {name}")
    print(f"Age: {age}")
    print(f"City: {city}")

student_info("Shafi", 22, "Kochi")
```

Output:

```text
Name: Shafi
Age: 22
City: Kochi
```

# 3. Return Values

`return` is used when a function needs to **send a result back** to the place where the function was called.

### Example

```python
def add(a, b):
    return a + b

result = add(10, 20)

print(result)
```

Output:

```text
30
```

The function calculates:

```python
10 + 20
```

and:

```python
return a + b
```

sends `30` back.

---

## `print()` vs `return`

This is very important.

### Using `print()`

```python
def add(a, b):
    print(a + b)

add(10, 20)
```

This displays the result.

### Using `return`

```python
def add(a, b):
    return a + b

result = add(10, 20)

print(result)
```

`return` allows us to **store and reuse the result**.

For example:

```python
def add(a, b):
    return a + b

result = add(10, 20)

new_result = result * 2

print(new_result)
```

Output:

```text
60
```

### Simple rule

> **print = show something**
> **return = send a value back**

# 4. Scope

**Scope** means where a variable can be accessed in a program.

There are two important scopes for beginners:

1. Local scope
2. Global scope

---

## Local Scope

A variable created **inside a function** is usually local to that function.

```python
def test():
    message = "Hello"
    print(message)

test()
```

This works.

But:

```python
def test():
    message = "Hello"

test()

print(message)
```

This gives an error because `message` exists only inside the function.

### Simple idea

```text
Outside function
      |
      v
  +---------+
  | Function|
  | message |
  +---------+
      |
      X
Cannot normally access message here
```

---

## Global Scope

A variable created outside a function is a **global variable**.

```python
name = "Shafi"

def greet():
    print(name)

greet()
```

Output:

```text
Shafi
```

The function can read the global variable.

### Beginner recommendation

Avoid using too many global variables. Prefer passing values through **parameters**.

Instead of:

```python
name = "Shafi"

def greet():
    print(name)
```

Prefer:

```python
def greet(name):
    print(name)

greet("Shafi")
```

This makes your code easier to understand and reuse.

# 5. Reusable Code

The biggest advantage of functions is **code reuse**.

Without a function:

```python
print("Checking IP address...")
print("Checking IP address...")
print("Checking IP address...")
```

With a function:

```python
def check_ip():
    print("Checking IP address...")

check_ip()
check_ip()
check_ip()
```

We write the code once and use it many times.

---

# Cybersecurity Example 1: Check Port

```python
def check_port(port):
    if port == 22:
        return "SSH port"
    elif port == 80:
        return "HTTP port"
    elif port == 443:
        return "HTTPS port"
    else:
        return "Unknown port"

print(check_port(22))
print(check_port(443))
print(check_port(8080))
```

Output:

```text
SSH port
HTTPS port
Unknown port
```

This combines:

* Function creation
* Parameter
* `if/elif/else`
* Return value

# Cybersecurity Example 2: Password Length Checker

```python
def check_password(password):
    if len(password) >= 8:
        return "Password length is acceptable"
    else:
        return "Password is too short"

print(check_password("hello"))
print(check_password("Hello123"))
```

Output:

```text

Password length is acceptable
```

This is only a **basic learning example**, not a complete password-security checker.

# Cybersecurity Example 3: IP Address Search

```python
def find_ip(ip, ip_list):
    if ip in ip_list:
        return "IP address found"
    else:
        return "IP address not found"


ips = [
    "192.168.1.10",
    "192.168.1.20",
    "10.0.0.5"
]

print(find_ip("192.168.1.10", ips))
print(find_ip("8.8.8.8", ips))
```

Output:

```text
IP address found
IP address not found
```

This is a good example of how functions work with **collections** from Task 3.

# Function with Default Parameter

You can give a parameter a default value.

```python
def greet(name="User"):
    print(f"Hello, {name}!")

greet("Shafi")
greet()
```

Output:

```text
Hello, Shafi!
Hello, User!
```

If no argument is provided, Python uses `"User"`.

---

# Function with Multiple Return Values

A function can return more than one value.

```python
def calculate(a, b):
    addition = a + b
    multiplication = a * b

    return addition, multiplication

result1, result2 = calculate(10, 5)

print(result1)
print(result2)
```

Output:

```text
15
50
```

```python
def check_age(age):
```

```python
def check_port(port):
    if port == 22:
        return "SSH"
    elif port == 80:
        return "HTTP"
    elif port == 443:
        return "HTTPS"
    else:
        return "Unknown"


def show_ports(ports):
    print("\n--- Port Information ---")

    for port in ports:
        print(f"Port {port}: {check_port(port)}")


# User input
username = input("Enter username: ")
age = int(input("Enter age: "))

# Collection
ports = [22, 80, 443, 443, 8080]

# Remove duplicates
unique_ports = set(ports)

# Dictionary
user = {

    "age": age
}

# Output
print("\n--- User Information ---")
print(f"Username: {user['username']}")
print(f"Age: {user['age']}")
print(f"Status: {check_age(age)}")

print(f"\nOriginal ports: {ports}")
print(f"Unique ports: {unique_ports}")

show_ports(unique_ports)
```
