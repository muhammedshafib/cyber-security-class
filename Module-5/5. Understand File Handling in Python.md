# 5. Understand File Handling in Python

File handling means **creating, opening, reading, writing, updating, and processing files using Python**.

It is very important in programming because data can be stored permanently in files instead of keeping it only in memory.

### Topics

1. Reading files
2. Writing files
3. CSV processing
4. JSON processing
5. Log file handling

---

## 1. Reading Files

Python provides the `open()` function to work with files.

### Basic syntax

```python
file = open("data.txt", "r")
```

* `"data.txt"` → filename
* `"r"` → read mode

Always close the file after use:

```python
file.close()
```

### Better method: `with open()`

```python
with open("data.txt", "r") as file:
    data = file.read()

print(data)
```

The file is automatically closed after the `with` block.

### `read()`

Reads the entire file.

```python
with open("data.txt", "r") as file:
    content = file.read()

print(content)
```

### `readline()`

Reads one line.

```python
with open("data.txt", "r") as file:
    line = file.readline()

print(line)
```

### `readlines()`

Reads all lines and returns them as a list.

```python
with open("data.txt", "r") as file:
    lines = file.readlines()

print(lines)
```

Example file:

```text
Python
Linux
Networking
Cybersecurity
```

Output:

```python
['Python\n', 'Linux\n', 'Networking\n', 'Cybersecurity\n']
```

### Reading line by line

This is better for large files:

```python
with open("data.txt", "r") as file:
    for line in file:
        print(line.strip())
```

`strip()` removes extra whitespace and the newline character.

# 2. Writing Files

Python can create a new file or overwrite an existing file.

## Write mode: `"w"`

```python
with open("data.txt", "w") as file:
    file.write("Hello Python")
```

⚠️ **Important:** `"w"` overwrites existing content.

For example:

```python
with open("data.txt", "w") as file:
    file.write("First line\n")
    file.write("Second line\n")
```

File becomes:

```text
First line
Second line
```

---

## Append mode: `"a"`

Append adds content to the end without deleting existing content.

```python
with open("data.txt", "a") as file:
    file.write("Third line\n")
```

Now:

```text
First line
Second line
Third line
```

---

## Write multiple lines

```python
lines = [
    "Python\n",
    "Linux\n",
    "Networking\n"
]

with open("data.txt", "w") as file:
    file.writelines(lines)
```

---

# File Modes

| Mode | Purpose                  |
| ---- | ------------------------ |
| `r`  | Read                     |
| `w`  | Write / overwrite        |
| `a`  | Append                   |
| `x`  | Create a new file        |
| `r+` | Read + write             |
| `w+` | Write + read, overwrites |
| `a+` | Append + read            |
| `b`  | Binary mode              |

Examples:

```python
open("file.txt", "r")
open("file.txt", "w")
open("file.txt", "a")
open("image.jpg", "rb")
```

# 3. CSV Processing

CSV means **Comma-Separated Values**.

Example:

```text
Name,Age,Course
Shafi,19,Cybersecurity
Arun,20,Python
Rahul,21,Networking
```

Python has a built-in `csv` module.

```python
import csv
```

## Reading CSV

```python
import csv

with open("students.csv", "r") as file:
    reader = csv.reader(file)

    for row in reader:
        print(row)
```

Output:

```text
['Name', 'Age', 'Course']
['Shafi', '19', 'Cybersecurity']
['Arun', '20', 'Python']
['Rahul', '21', 'Networking']
```

---

## Reading CSV using `DictReader`

This is easier when working with columns.

```python
import csv

with open("students.csv", "r") as file:
    reader = csv.DictReader(file)

    for row in reader:
        print(row["Name"])
        print(row["Course"])
```

Output:

```text
Shafi
Cybersecurity
Arun
Python
Rahul
Networking
```

---

## Writing CSV

```python
import csv

with open("students.csv", "w", newline="") as file:
    writer = csv.writer(file)

    writer.writerow(["Name", "Age", "Course"])
    writer.writerow(["Shafi", 19, "Cybersecurity"])
    writer.writerow(["Arun", 20, "Python"])
```

---

## Writing multiple CSV rows

```python
import csv

students = [
    ["Name", "Age", "Course"],
    ["Shafi", 19, "Cybersecurity"],
    ["Arun", 20, "Python"],
    ["Rahul", 21, "Networking"]
]

with open("students.csv", "w", newline="") as file:
    writer = csv.writer(file)
    writer.writerows(students)
```

# 4. JSON Processing

JSON means **JavaScript Object Notation**.

It is commonly used for storing structured data and communicating between applications/APIs.

Example:

```json
{
    "name": "Shafi",
    "age": 19,
    "course": "Cybersecurity"
}
```

Python uses the built-in `json` module.

```python
import json
```

---

## Writing JSON

```python
import json

student = {
    "name": "Shafi",
    "age": 19,
    "course": "Cybersecurity"
}

with open("student.json", "w") as file:
    json.dump(student, file, indent=4)
```

The file will contain:

```json
{
    "name": "Shafi",
    "age": 19,
    "course": "Cybersecurity"
}
```

`indent=4` makes the JSON easier to read.

---

## Reading JSON

```python
import json

with open("student.json", "r") as file:
    data = json.load(file)

print(data)
```

Output:

```python
{'name': 'Shafi', 'age': 19, 'course': 'Cybersecurity'}
```

Access individual values:

```python
print(data["name"])
print(data["course"])
```

Output:

```text
Shafi
Cybersecurity
```

---

## `dump()` vs `dumps()`

### `json.dump()`

Writes JSON directly to a file.

```python
json.dump(data, file)
```

### `json.dumps()`

Converts Python data into a JSON string.

```python
json_string = json.dumps(data)

print(json_string)
```

Similarly:

* `json.load()` → JSON file → Python object
* `json.loads()` → JSON string → Python object

### Important conversion

```text
Python dictionary
       ↓
   json.dump()
       ↓
    JSON file
       ↓
   json.load()
       ↓
Python dictionary
```

# 5. Log File Handling

A **log file** records events that happen inside a program or system.

Example:

```text
2026-09-03 10:30:15 INFO User logged in
2026-09-03 10:32:20 WARNING Failed login attempt
2026-09-03 10:35:12 ERROR Database connection failed
```

Logs are extremely important in **cybersecurity, system administration, debugging, and incident investigation**.

Python provides the `logging` module.

```python
import logging
```

## Basic logging

```python
import logging

logging.basicConfig(
    filename="app.log",
    level=logging.INFO
)

logging.info("Program started")
logging.warning("Low disk space")
logging.error("Something went wrong")
```

This creates:

```text
app.log
```

---

# Log Levels

Python provides several standard log levels:

| Level      | Purpose                        |
| ---------- | ------------------------------ |
| `DEBUG`    | Detailed debugging information |
| `INFO`     | Normal program activity        |
| `WARNING`  | Something unexpected           |
| `ERROR`    | An operation failed            |
| `CRITICAL` | Serious failure                |

Example:

```python
logging.debug("Debug information")
logging.info("User logged in")
logging.warning("Multiple failed attempts")
logging.error("File not found")
logging.critical("System failure")
```

By default, `INFO` and above can be recorded when the logging level is set to `INFO`.

---

# Better Log Format

```python
import logging

logging.basicConfig(
    filename="app.log",
    level=logging.INFO,
    format="%(asctime)s - %(levelname)s - %(message)s"
)

logging.info("Application started")
logging.warning("Invalid login attempt")
logging.error("Unable to open file")
```

Example:

```text
2026-09-03 22:10:15,123 - INFO - Application started
2026-09-03 22:10:20,452 - WARNING - Invalid login attempt
2026-09-03 22:10:25,781 - ERROR - Unable to open file
```

# File Handling Error Management

Files may not exist, permissions may be insufficient, etc.

Use `try-except`.

```python
try:
    with open("data.txt", "r") as file:
        data = file.read()

    print(data)

except FileNotFoundError:
    print("File does not exist.")

except PermissionError:
    print("Permission denied.")
```

You can also catch general I/O errors:

```python
try:
    with open("data.txt", "r") as file:
        data = file.read()

except OSError as e:
    print("File error:", e)
```
