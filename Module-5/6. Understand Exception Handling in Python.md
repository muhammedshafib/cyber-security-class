# 6. Understand Exception Handling in Python

Exception handling means **handling errors in a program without suddenly stopping the program**.

For example:

```python
age = int(input("Enter your age: "))
print(age)
```

If the user enters:

```text
hello
```

Python gives an error:

```text
ValueError
```

Instead of allowing the program to crash, we can handle the error.

---

## 1. Error Handling

An **error** is a problem that prevents your program from working correctly.

### Common Python errors

| Error               | Meaning                      |
| ------------------- | ---------------------------- |
| `ValueError`        | Wrong value/type of value    |
| `TypeError`         | Wrong data type operation    |
| `ZeroDivisionError` | Dividing by zero             |
| `FileNotFoundError` | File doesn't exist           |
| `NameError`         | Variable doesn't exist       |
| `IndexError`        | Invalid list index           |
| `KeyError`          | Dictionary key doesn't exist |

### Example

```python
number = 10
result = number / 0
```

Output:

```text
ZeroDivisionError
```

The program stops.

Exception handling allows us to handle this situation.

---

# 2. `try-except` Blocks

The basic structure is:

```python
try:
    # code that may cause an error
except:
    # what to do if an error happens
```

### Simple example

```python
try:
    number = int(input("Enter a number: "))
    print(number)
except:
    print("Please enter a valid number")
```

If the user enters:

```text
25
```

Output:

```text
25
```

If the user enters:

```text
hello
```

Output:

```text
Please enter a valid number
```

The program doesn't crash.

---

## Catch a specific error

It is better to specify the error.

```python
try:
    number = int(input("Enter a number: "))
except ValueError:
    print("You must enter a number")
```

### Why use `ValueError`?

Because we know exactly what error we are expecting.

---

## Multiple `except`

You can handle different errors separately.

```python
try:
    number = int(input("Enter number: "))
    result = 100 / number
    print(result)

except ValueError:
    print("Enter numbers only")

except ZeroDivisionError:
    print("Cannot divide by zero")
```

For input:

```text
abc
```

Output:

```text
Enter numbers only
```

For input:

```text
0
```

Output:

```text
Cannot divide by zero
```

---

# `else`

`else` runs **only when there is no error**.

```python
try:
    number = int(input("Enter number: "))
except ValueError:
    print("Invalid number")
else:
    print("You entered:", number)
```

Flow:

```text
try
 ↓
Error?
 ├── YES → except
 └── NO  → else
```

---

# `finally`

`finally` runs **whether an error happens or not**.

```python
try:
    file = open("data.txt", "r")
    print(file.read())

except FileNotFoundError:
    print("File not found")

finally:
    print("Program finished")
```

`finally` is useful for cleanup operations.

---

# 3. Debugging

**Debugging** means finding and fixing problems in your program.

Suppose:

```python
a = 10
b = 20

result = a - b

print(result)
```

Output:

```text
-10
```

Maybe you expected `30`.

You need to find where the problem is.

### Using `print()` for debugging

```python
a = 10
b = 20

print("a =", a)
print("b =", b)

result = a + b

print("result =", result)
```

Output:

```text
a = 10
b = 20
result = 30
```

`print()` helps you see what your program is doing.

---

## Using `pdb`

Python also has a built-in debugger called `pdb`.

```python
import pdb

x = 10
y = 20

pdb.set_trace()

result = x + y

print(result)
```

When Python reaches:

```python
pdb.set_trace()
```

it pauses the program and allows you to inspect variables.

For beginners, start with `print()` debugging and then learn `pdb`.

---

# 4. Logging Errors

**Logging** means recording what happens inside your program.

Instead of only displaying an error:

```python
print("Error occurred")
```

we can save the error in a file.

### Simple example

```python
import logging

logging.basicConfig(
    filename="app.log",
    level=logging.ERROR
)

try:
    number = 10 / 0

except ZeroDivisionError:
    logging.error("Tried to divide by zero")
    print("Cannot divide by zero")
```

The user sees:

```text
Cannot divide by zero
```

And `app.log` contains something like:

```text
ERROR:root:Tried to divide by zero
```

---

## `logging.exception()`

For errors, `logging.exception()` is very useful because it records the error information.

```python
import logging

logging.basicConfig(
    filename="app.log",
    level=logging.ERROR
)

try:
    number = 10 / 0

except Exception:
    logging.exception("An error occurred")
```

The log can contain the error and traceback information.

This is especially useful when debugging larger programs.

# 5. Building Reliable Scripts

A **reliable script** should:

* Handle expected errors
* Validate user input
* Give useful error messages
* Log important errors
* Avoid crashing unnecessarily
* Clean up resources
* Use specific exceptions
* Test different situations

### Bad example

```python
age = int(input("Enter age: "))

print("Your age is", age)
```

If the user enters:

```text
abc
```

the program crashes.

### Better example

```python
while True:

    try:
        age = int(input("Enter your age: "))

        if age < 0:
            print("Age cannot be negative")
            continue

        print("Your age is:", age)
        break

    except ValueError:
        print("Please enter a valid number")
```

Now the program keeps asking until the user enters valid information.

---

# Complete Example

Here is a small program combining **exception handling + debugging + logging**:

```python
import logging

logging.basicConfig(
    filename="app.log",
    level=logging.ERROR
)

try:
    number1 = int(input("Enter first number: "))
    number2 = int(input("Enter second number: "))

    print("DEBUG: Numbers received")

    result = number1 / number2

    print("Result:", result)

except ValueError:
    print("Error: Please enter numbers only")
    logging.error("User entered an invalid number")

except ZeroDivisionError:
    print("Error: Cannot divide by zero")
    logging.error("Division by zero occurred")

except Exception as e:
    print("Something went wrong")
    logging.exception("Unexpected error")
```

### Flow

```text
User input
    ↓
   try
    ↓
Is there an error?
   /       \
 YES       NO
 ↓          ↓
except    continue
 ↓          ↓
log error  result
 ↓          ↓
message   program
```

## Exception Handling Cheat Sheet

```python
try:
    # risky code
```

```python
except ValueError:
    # handle ValueError
```

```python
except ZeroDivisionError:
    # handle division by zero
```

```python
else:
    # runs when no error occurs
```

```python
finally:
    # always runs
```

```python
raise ValueError("Invalid value")
```

```python
logging.error("Error occurred")
```

```python
logging.exception("Unexpected error")
```

### Important difference

**Error handling** → deals with errors.

**`try-except`** → catches and handles exceptions.

**Debugging** → finds the cause of problems.

**Logging** → records program events/errors.

**Reliable script** → continues working safely even when expected problems occur.

For cybersecurity, exception handling and logging are especially useful when writing **log-analysis, network-monitoring, file-processing, and security scripts**.
