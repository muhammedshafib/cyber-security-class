# 1. Importing Modules

## What is a module?

A **module** is simply a Python file containing code that you can reuse.

For example:

```text
calculator.py
```

can contain:

```python
def add(a, b):
    return a + b
```

Another file can import it:

```python
from calculator import add

print(add(10, 20))
```

Think:

```text
calculator.py
       ↓
    import
       ↓
    main.py
```

Instead of writing the same code repeatedly, you reuse it.

---

## 1.1 Built-in Modules

Python comes with many modules.

### `math`

```python
import math

print(math.sqrt(25))
print(math.pi)
```

Output:

```text
5.0
3.141592...
```

---

### `os`

```python
import os

print(os.getcwd())
```

`os` lets Python interact with the operating system.

---

### `json`

```python
import json

data = {
    "username": "alice",
    "active": True
}

text = json.dumps(data)

print(text)
```

---

### `socket`

```python
import socket

hostname = socket.gethostname()

print(hostname)
```

Useful for learning networking.

---

# 1.2 Different Import Styles

### Import the whole module

```python
import math

print(math.sqrt(16))
```

### Import a specific function

```python
from math import sqrt

print(sqrt(16))
```

### Import with an alias

```python
import math as m

print(m.sqrt(16))
```

For beginners, prefer clear imports:

```python
import math
```

or:

```python
from math import sqrt
```

Avoid unnecessary aliases that make code difficult to understand.

# 1.3 Why Modules Matter in Security

Imagine you create:

```text
password_utils.py
log_utils.py
hash_utils.py
validators.py
```

Then your main program can reuse them:

```python
from password_utils import check_password
from hash_utils import calculate_hash
from log_utils import analyze_log
```

This makes a security project easier to maintain.

# 2. Creating Your Own Modules

Let's build one.

## Step 1 — Create a folder

```text
security_project/
```

Inside it:

```text
security_project/
│
├── main.py
└── security_utils.py
```

---

## Step 2 — Create `security_utils.py`

```python
def is_strong_password(password):
    if len(password) < 8:
        return False

    has_digit = any(char.isdigit() for char in password)
    has_upper = any(char.isupper() for char in password)

    return has_digit and has_upper
```

This file contains reusable security-related logic.

---

## Step 3 — Create `main.py`

```python
from security_utils import is_strong_password


password = input("Enter password: ")

if is_strong_password(password):
    print("Password meets the basic requirements.")
else:
    print("Password does not meet the basic requirements.")
```

Run:

```bash
python main.py
```

---

## How It Works

```text
main.py
   │
   │ imports
   ↓
security_utils.py
   │
   ↓
is_strong_password()
   │
   ↓
True / False
   │
   ↓
main.py
```

The important concept is:

> **Put reusable logic in modules and keep the main program focused on using that logic.**

# 2.1 `__name__` and `__main__`

You will often see:

```python
def main():
    print("Security tool started")


if __name__ == "__main__":
    main()
```

Why?

Suppose `security_utils.py` contains:

```python
def check():
    print("Checking...")


if __name__ == "__main__":
    check()
```

If you run:

```bash
python security_utils.py
```

Python executes:

```python
check()
```

But if another file imports it:

```python
from security_utils import check
```

the `check()` function isn't automatically executed.

This is useful for reusable modules.

# 2.2 Multiple Modules

A realistic project might look like:

```text
security_project/
│
├── main.py
│
├── security/
│   ├── __init__.py
│   ├── password_utils.py
│   ├── hash_utils.py
│   ├── log_utils.py
│   └── validators.py
│
└── requirements.txt
```

Each module has a responsibility.

```text
password_utils.py → password-related functions
hash_utils.py     → file hashing
log_utils.py      → log processing
validators.py     → input validation
main.py           → program coordination
```

This is much better than putting 1,000 lines into `main.py`.

# 3. Package Management

A **package** is a way of organizing related Python modules.

You will also hear:

```text
module
package
library
framework
```

These aren't exactly the same thing.

### Module

Usually one `.py` file:

```text
hash_utils.py
```

### Package

A collection of related Python modules:

```text
security/
├── hash_utils.py
├── log_utils.py
└── validators.py
```

### Library

A broader collection of reusable functionality, often distributed as installable packages.

# 4. Virtual Environments

This is one of the most important concepts.

Suppose you have:

```text
Project A → requests version A
Project B → requests version B
```

Installing everything globally can cause conflicts.

A **virtual environment** gives each project an isolated Python environment.

Think:

```text
Computer
│
├── Project A
│   └── .venv
│       └── packages
│
└── Project B
    └── .venv
        └── packages
```

---

# 4.1 Create a Virtual Environment on Windows

Create the environment:


Now:

```text
security_project/
└── .venv/
```

# 5. Reusable Security Tools 🔐

Now we combine everything.

# Tool 1 — Password Strength Checker

Create:

```text
security/password_utils.py
```

```python
def check_password_strength(password):
    score = 0

    if len(password) >= 8:
        score += 1

    if any(char.isupper() for char in password):
        score += 1

    if any(char.islower() for char in password):
        score += 1

    if any(char.isdigit() for char in password):
        score += 1

    if score <= 2:
        return "Weak"

    if score == 3:
        return "Medium"

    return "Strong"
```

Then:

```python
from security.password_utils import check_password_strength


password = input("Enter password: ")

result = check_password_strength(password)

print("Strength:", result)
```

### Concepts used

```text
Function
↓
String
↓
Condition
↓
Loop/generator expression
↓
Module
↓
Import
```

This is a simple educational strength indicator, **not a password-storage system**.

---

# Tool 2 — File Hash Utility

Create:

```text
security/hash_utils.py
```

```python
import hashlib


def calculate_sha256(filename):
    sha256 = hashlib.sha256()

    with open(filename, "rb") as file:
        while chunk := file.read(4096):
            sha256.update(chunk)

    return sha256.hexdigest()
```

Use it:

```python
from security.hash_utils import calculate_sha256


filename = input("Enter filename: ")

try:
    result = calculate_sha256(filename)
    print("SHA-256:", result)

except FileNotFoundError:
    print("File not found.")
```

### Why is this useful?

You can calculate a file's hash and later compare it with another hash to detect unexpected changes.

# Tool 3 — Log Analyzer

Create:

```text
security/log_utils.py
```

```python
from collections import Counter


def count_log_levels(filename):
    levels = Counter()

    with open(filename, "r") as file:
        for line in file:
            parts = line.split()

            if parts:
                levels[parts[0]] += 1

    return levels
```

Use:

```python
from security.log_utils import count_log_levels


try:
    result = count_log_levels("security.log")

    for level, count in result.items():
        print(f"{level}: {count}")

except FileNotFoundError:
    print("Log file not found.")
```

---

# Tool 4 — Input Validator

Create:

```text
security/validators.py
```

```python
def is_valid_username(username):
    if not username:
        return False

    if len(username) > 50:
        return False

    return username.isalnum()
```

Use:

```python
from security.validators import is_valid_username


username = input("Username: ")

if is_valid_username(username):
    print("Valid username")
else:
    print("Invalid username")
```

Input validation is important because **untrusted input should not automatically be treated as safe**.

# 🔥 Final Project — Security Toolkit

Now combine everything.

```text
security_toolkit/
│
├── .venv/
│
├── main.py
│
├── requirements.txt
│
└── security/
    ├── __init__.py
    ├── password_utils.py
    ├── hash_utils.py
    ├── log_utils.py
    └── validators.py
```

Your `main.py` can become:

```python
from security.password_utils import check_password_strength
from security.hash_utils import calculate_sha256
from security.log_utils import count_log_levels
from security.validators import is_valid_username


def main():
    print("=== SECURITY TOOLKIT ===")

    username = input("Enter username: ")

    if is_valid_username(username):
        print("Username is valid.")
    else:
        print("Username is invalid.")

    password = input("Enter password: ")

    print(
        "Password strength:",
        check_password_strength(password)
    )

    filename = input("Enter file to hash: ")

    try:
        print(
            "SHA-256:",
            calculate_sha256(filename)
        )
    except FileNotFoundError:
        print("File not found.")

    try:
        results = count_log_levels("security.log")

        print("\nLog summary:")

        for level, count in results.items():
            print(f"{level}: {count}")

    except FileNotFoundError:
        print("security.log not found.")


if __name__ == "__main__":
    main()
```

# ⚠️ Common Beginner Mistakes

### Mistake 1

Installing packages before activating `.venv`.

Check:

```text
(.venv)
```

before installing.

---

### Mistake 2

Using:

```cmd
pip install requests
```

when multiple Python installations exist.

Prefer:

```cmd
python -m pip install requests
```

---

### Mistake 3

Putting everything in `main.py`.

Instead:

```text
main.py
security/
    utils.py
    validators.py
    hash_utils.py
```

---

### Mistake 4

Hard-coding secrets.

Don't do:

```python
API_KEY = "real-secret-key"
```

Use environment variables or a proper secrets-management solution.

---

### Mistake 5

Uploading `.venv` to Git.

Use:

```text
.venv/
```

in `.gitignore`.
