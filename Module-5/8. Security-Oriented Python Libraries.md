# 🔐 8. Security-Oriented Python Libraries

These five Python modules are very useful when learning **cybersecurity, ethical hacking, automation, networking, and security tools**.

We’ll learn:

1. `requests` → communicate with websites/APIs
2. `json` → work with structured data
3. `os` → interact with the operating system
4. `socket` → network communication
5. `subprocess` → safely run external programs

> **Important:** These libraries are legitimate general-purpose tools. For security learning, use them only on systems you own or have explicit permission to test.

# 1. `requests` — Communicate With Websites 🌐

`requests` lets Python send HTTP requests to websites and APIs.

Think:

```text
Python
   ↓
HTTP Request
   ↓
Website / API
   ↓
HTTP Response
   ↓
Python
```

## Install Requests

Inside your virtual environment:

```bash
python -m pip install requests
```

Check:

```bash
python -m pip show requests
```

---

## GET Request

```python
import requests

response = requests.get("https://example.com")

print(response.status_code)
print(response.text)
```

### What is `status_code`?

Common HTTP status codes:

|  Code | Meaning      |
| ----: | ------------ |
| `200` | Success      |
| `301` | Redirect     |
| `400` | Bad request  |
| `401` | Unauthorized |
| `403` | Forbidden    |
| `404` | Not found    |
| `500` | Server error |

---

## Check if Request Was Successful

```python
import requests

response = requests.get("https://example.com")

if response.status_code == 200:
    print("Website is reachable")
else:
    print("Request failed")
```

---

## Timeout — Very Important

Never let a network request wait forever.

```python
import requests

response = requests.get(
    "https://example.com",
    timeout=5
)

print(response.status_code)
```

`timeout=5` means:

> Wait up to approximately 5 seconds for the request operation before raising a timeout-related exception.

---

## Handle Errors

```python
import requests

try:
    response = requests.get(
        "https://example.com",
        timeout=5
    )

    response.raise_for_status()

    print("Success!")

except requests.RequestException as error:
    print("Request failed:", error)
```

This is much better for real programs.

# 2. `json` — Work With Structured Data 📦

JSON means:

**JavaScript Object Notation**

It's extremely common in:

* APIs
* configuration files
* web applications
* security tools
* logs
* databases

Example JSON:

```json
{
    "name": "Ali",
    "age": 21,
    "skills": ["Python", "Linux", "Networking"]
}
```

---

## JSON → Python

Use:

```python
json.loads()
```

Example:

```python
import json

data = '''
{
    "name": "Ali",
    "age": 21
}
'''

student = json.loads(data)

print(student["name"])
print(student["age"])
```

Output:

```text
Ali
21
```

### Mental model

```text
JSON string
     ↓
json.loads()
     ↓
Python dictionary
```

---

# Python → JSON

Use:

```python
json.dumps()
```

Example:

```python
import json

student = {
    "name": "Ali",
    "age": 21
}

data = json.dumps(student)

print(data)
```

Output:

```text
{"name": "Ali", "age": 21}
```

---

# JSON File

Suppose you have:

```text
config.json
```

You can read it:

```python
import json

with open("config.json", "r") as file:
    config = json.load(file)

print(config)
```

Notice the difference:

```python
json.loads()
```

→ JSON **string**

```python
json.load()
```

→ JSON **file**

---

## Write JSON

```python
import json

data = {
    "username": "admin",
    "enabled": True
}

with open("config.json", "w") as file:
    json.dump(data, file, indent=4)
```

The file becomes:

```json
{
    "username": "admin",
    "enabled": true
}
```

# 3. `os` — Interact With Windows 💻

The `os` module allows Python to interact with the operating system.

You can use it to:

* inspect environment variables
* work with directories
* inspect files
* get system information
* manipulate paths

---

## Current Directory

```python
import os

```

Example:

```text
C:\Users\Ali\python_project
```

---


Possible output:



---

## Check File vs Directory

```python

```

# Environment Variables

Environment variables are important in security.

For example, instead of putting a secret directly into Python:

❌ Don't do this:

```python
API_KEY = "my-secret-key"
```

Instead, use an environment variable.

On Windows PowerShell:

```powershell
$env:API_KEY="my-secret-key"
```

Python:

```python
import os

api_key = os.getenv("API_KEY")

print(api_key)
```

This helps keep secrets out of your source code.

> Be careful not to print real secrets in logs or terminal output.

# 4. `socket` — Network Communication 🌐

The `socket` module provides low-level networking.

It's useful for understanding:

* IP addresses
* ports
* TCP
* UDP
* client/server communication
* network programming

---

## What is a Socket?

Think of:

```text
IP address + Port
```

as an address for a network service.

For example:

```text
127.0.0.1:8080
```

means:

```text
127.0.0.1 → local computer
8080       → port
```

---

# Get Your Computer's Hostname

```python
import socket

hostname = socket.gethostname()

print(hostname)
```

---

# Get an IP Address

```python
import socket

hostname = socket.gethostname()
ip = socket.gethostbyname(hostname)

print("Hostname:", hostname)
print("IP:", ip)
```

---

# Connect to a Website

For basic networking practice:

```python
import socket

sock = socket.socket(socket.AF_INET, socket.SOCK_STREAM)

sock.settimeout(5)

sock.connect(("example.com", 80))

print("Connection successful")

sock.close()
```

### Breaking it down

```python
socket.AF_INET
```

means IPv4.

```python
socket.SOCK_STREAM
```

means TCP.

So:

```python
socket.socket(
    socket.AF_INET,
    socket.SOCK_STREAM
)
```

creates an IPv4 TCP socket.

---

# Better Version With `with`

```python
import socket

try:
    with socket.socket(socket.AF_INET, socket.SOCK_STREAM) as sock:
        sock.settimeout(5)
        sock.connect(("example.com", 80))

        print("Connected!")

except OSError as error:
    print("Connection failed:", error)
```

The socket automatically closes when the `with` block finishes.

---

# ⚠️ Security Learning

Sockets are often used for security testing, but don't scan or probe random computers or networks without authorization.

For practice, use:

```text
127.0.0.1
```

or your own lab environment.

# 5. `subprocess` — Run External Programs ⚙️

`subprocess` allows Python to execute another program.

For example, Python can run:

```text
ipconfig
ping
whoami
python
```

on Windows.

---

# Run `ipconfig`

```python
import subprocess

result = subprocess.run(
    ["ipconfig"],
    capture_output=True,
    text=True
)

print(result.stdout)
```

---

## Understanding `subprocess.run()`

```python
subprocess.run(
    ["ipconfig"],
    capture_output=True,
    text=True
)
```

### `["ipconfig"]`

The command and its arguments.

### `capture_output=True`

Capture the program's output.

### `text=True`

Return output as normal Python strings rather than bytes.

---

# Check the Exit Code

```python
import subprocess

result = subprocess.run(
    ["ipconfig"],
    capture_output=True,
    text=True
)

print("Exit code:", result.returncode)
```

Usually:

```text
0
```

means the command completed successfully.

---

# Run `whoami`

```python
import subprocess

result = subprocess.run(
    ["whoami"],
    capture_output=True,
    text=True
)

print(result.stdout)
```

This tells you the Windows account running the command.

---

# ⚠️ Very Important Security Rule

Avoid doing this with untrusted input:

```python
subprocess.run(user_input, shell=True)
```

This can create **command injection** vulnerabilities.

Prefer:

```python
subprocess.run(
    ["ping", "-n", "1", "example.com"],
    capture_output=True,
    text=True
)
```

Instead of constructing shell commands from raw user input.

# 🛡️ Mini Project: Basic System Information Tool

Let's combine `os` and `subprocess`.

Create:

```text
security_info.py
```

Code:

```python
import os
import socket
import subprocess


def show_system_info():
    print("=== SYSTEM INFORMATION ===")

    print("Hostname:", socket.gethostname())
    print("Current directory:", os.getcwd())


def show_network_info():
    print("\n=== NETWORK INFORMATION ===")

    result = subprocess.run(
        ["ipconfig"],
        capture_output=True,
        text=True
    )

    print(result.stdout)


show_system_info()
show_network_info()
```

Run:

```bash
python security_info.py
```

You'll get information about your own Windows computer.

# 🔥 Mini Project 2: Website Status Checker

Now combine:

* `requests`
* `json`

Create:

```text
website_checker.py
```

```python
import requests
import json


url = "https://example.com"

try:
    response = requests.get(url, timeout=5)

    result = {
        "url": url,
        "status_code": response.status_code,
        "reachable": response.ok
    }

    print(json.dumps(result, indent=4))

except requests.RequestException as error:
    result = {
        "url": url,
        "reachable": False,
        "error": str(error)
    }

    print(json.dumps(result, indent=4))
```

Output:

```json
{
    "url": "https://example.com",
    "status_code": 200,
    "reachable": true
}
```

This is a good foundation for monitoring tools.

# 🧠 Remember the Difference

| Library      | Main Purpose           | Example           |
| ------------ | ---------------------- | ----------------- |
| `requests`   | HTTP/web communication | API request       |
| `json`       | Structured data        | API/config data   |
| `os`         | Operating system       | Files/environment |
| `socket`     | Network communication  | TCP connection    |
| `subprocess` | External programs      | `ipconfig`        |

### Easy memory trick:

```text
Requests → Web
JSON     → Data
OS       → Computer
Socket   → Network
Subprocess → Commands
```
