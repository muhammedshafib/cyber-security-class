# 7. Understand Script Scheduling

**Script scheduling** means automatically running a Python script at a specific time or at regular intervals.

For example:

```text
Every day at 9:00 AM
        ↓
Run security_check.py
        ↓
Check logs
        ↓
Generate report
        ↓
Create alert if needed
```

This is useful because security tasks often need to run **automatically without a person starting the script manually**.

---

# 7.1 Scheduled Execution

## What is scheduled execution?

Scheduled execution means:

> Run a program automatically at a particular time or interval.

Examples:

```text
Every 5 minutes  → Check system
Every hour       → Check logs
Every day        → Generate report
Every week       → Run maintenance task
```

### Manual execution

You type:

```text
python monitor.py
```

every time.

### Scheduled execution

The operating system automatically runs:

```text
python monitor.py
```

at the configured time.

---

# 7.2 Automated Tasks

## What is an automated task?

An automated task is something the computer performs without requiring you to manually start it each time.

Examples in cybersecurity:

* Check log files
* Check disk space
* Monitor CPU
* Check a service
* Detect file changes
* Generate reports
* Count failed logins
* Create alerts

For example:

```python
import psutil

disk = psutil.disk_usage("C:\\").percent

print("Disk usage:", disk, "%")

if disk >= 90:
    print("ALERT: Disk usage is high")
```

Instead of running this manually every day, we can schedule it.

# 7.5 Monitoring Execution

Scheduling a script isn't enough.

We should also know:

> Did the script actually run successfully?

This is **execution monitoring**.

For example:

```text
Scheduled job
      ↓
Script runs
      ↓
Success?
   /      \
 YES       NO
 ↓         ↓
Log       Alert
```

---

# Simple Execution Logging

We can write a message into a log file.

```python
from datetime import datetime

time = datetime.now()

with open("execution.log", "a") as file:
    file.write("Security check ran: " + str(time) + "\n")

print("Task completed")
```

The `"a"` means:

```text
append
```

It adds new information without deleting the old information.

Example `execution.log`:

```text
Security check ran: 2026-09-17 19:10:02
Security check ran: 2026-09-17 19:15:02
Security check ran: 2026-09-17 19:20:02
```

Now we can see whether the task has been running.

---

# 7.6 Checking Success or Failure

Python provides an exit status.

```python
print("Task completed successfully")
```

For scripts, a common convention is:

```text
0     → Success
non-0 → Error/failure
```

You can explicitly use:

```python
import sys

print("Security check completed")

sys.exit(0)
```

`0` normally means successful completion.

For an error:

```python
import sys

print("Security check failed")

sys.exit(1)
```

`1` indicates failure.

---

# 7.7 Exception Handling for Reliable Scheduling

A scheduled script should not crash unexpectedly.

Use:

```python
try:
    # task
except:
    # handle error
```

Example:

```python
import psutil

try:

    cpu = psutil.cpu_percent()

    print("CPU:", cpu, "%")

except Exception as error:

    print("Error:", error)
```

This prevents an unexpected error from immediately ending the program without useful information.

---

# Better Version with Logging

```python
import psutil
from datetime import datetime

try:

    cpu = psutil.cpu_percent()

    print("CPU:", cpu, "%")

    with open("execution.log", "a") as file:
        file.write(
            str(datetime.now()) +
            " - Security check successful\n"
        )

except Exception as error:

    with open("execution.log", "a") as file:
        file.write(
            str(datetime.now()) +
            " - ERROR: " +
            str(error) +
            "\n"
        )
```

Now both successful and failed executions are recorded.

# 7.8 Reliability Considerations

A scheduled security script should be reliable.

There are several important points.

## 1. Error handling

Don't allow unexpected errors to silently stop the task.

```python
try:
    # code
except Exception as error:
    print(error)
```

---

## 2. Logging

Record what happened.

```python
with open("execution.log", "a") as file:
    file.write("Task completed\n")
```

---

## 3. Timeouts

If your script communicates with a network service, don't let it wait forever.

Example:

```python
sock.settimeout(5)
```

This is something you already learned in **socket programming**.

---

## 4. Avoid duplicate jobs

Be careful not to accidentally create:

```text
Job 1 → runs every 5 minutes
Job 2 → runs every 5 minutes
Job 3 → runs every 5 minutes
```

This could cause the same task to run multiple times.

---

## 5. Check dependencies

If your script requires:

```python
import psutil
```

make sure `psutil` is installed in the Python environment used by the scheduler.

---

## 6. Use absolute paths when appropriate

Instead of relying on:

```python
open("security.log")
```

a scheduled task may work more reliably with a known project path.

The working directory used by a scheduler may be different from the directory used when you run the script manually.

---

## 7. Protect sensitive information

Don't put passwords or API keys directly into:

```python
password = "mypassword"
```

or log them into files.

Scheduled scripts may run unattended, so secret handling is especially important.

# 7.9 Scheduled Log Analyzer

Let's connect scheduling with your previous **Log Processing Automation** topic.

Suppose we have:

```text
auth.log
```

containing:

```text
Failed login alice 10.0.0.5
Successful login bob 10.0.0.8
Failed login admin 10.0.0.5
Failed login root 10.0.0.5
```

Create:

```text
log_check.py
```

```python
from collections import Counter

failed_ips = []

with open("auth.log", "r") as file:

    for line in file:

        if "Failed login" in line:

            ip = line.split()[-1]

            failed_ips.append(ip)

counts = Counter(failed_ips)

print("SECURITY REPORT")
print("----------------")

for ip, count in counts.items():

    print(ip, "→", count, "failed attempts")

    if count >= 3:
        print("ALERT: Suspicious activity")
```

Now imagine Task Scheduler runs this every hour.

```text
Every hour
    ↓
log_check.py
    ↓
Read auth.log
    ↓
Analyze failed logins
    ↓
Count IP addresses
    ↓
Generate alert
```

This is a real example of combining:

**Log Processing + Security Data Processing + Scheduling**

# 7.11 Simple Scheduler Inside Python

You can also create a repeating task directly in Python.

```python
import time

while True:

    print("Security check running")

    time.sleep(60)
```

This runs approximately every 60 seconds.

Workflow:

```text
Run check
   ↓
Wait 60 seconds
   ↓
Run check
   ↓
Wait 60 seconds
   ↓
Repeat
```

Stop it with:

```text
Ctrl + C
```

### Important difference

There are two common approaches:

```text
Operating-system scheduler
        ↓
Windows Task Scheduler
```

or:

```text
Python program
        ↓
while loop + time.sleep()
```

For long-running or production-style tasks, an OS scheduler or dedicated job scheduler can be preferable because the scheduling is separated from the script itself.

# 7.12 Complete Beginner Project

Let's create a simple scheduled security check.

### File structure

```text
security_scheduler/
│
├── security_check.py
└── execution.log
```

### `security_check.py`

```python
import psutil
from datetime import datetime

try:

    cpu = psutil.cpu_percent()
    memory = psutil.virtual_memory().percent
    disk = psutil.disk_usage("C:\\").percent

    print("SECURITY CHECK")
    print("----------------")

    print("CPU:", cpu, "%")
    print("Memory:", memory, "%")
    print("Disk:", disk, "%")

    with open("execution.log", "a") as file:

        file.write(
            str(datetime.now()) +
            " - Check completed\n"
        )

    if cpu >= 80:
        print("ALERT: High CPU usage")

    if memory >= 80:
        print("ALERT: High memory usage")

    if disk >= 90:
        print("ALERT: High disk usage")


except Exception as error:

    print("ERROR:", error)

    with open("execution.log", "a") as file:

        file.write(
            str(datetime.now()) +
            " - ERROR: " +
            str(error) +
            "\n"
        )
```

Run manually first:

```text
python security_check.py
```

Make sure it works **before** scheduling it.

| Topic                    | Simple meaning                                    |
| ------------------------ | ------------------------------------------------- |
| **Scheduled execution**  | Run a script automatically at a specific time     |
