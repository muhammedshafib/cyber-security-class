## 1. Build Log Analysis Scripts

A log analysis script reads a log file and finds important security events.

### Example: Count failed logins

```python
failed = 0

with open("security.log", "r") as file:
    for line in file:
        if "FAILED" in line:
            failed = failed + 1

print("Failed logins:", failed)
```

### What it does

```text
security.log
     ↓
Read each line
     ↓
Find "FAILED"
     ↓
Count failures
     ↓
Display result
```

### Practice task

Create a script that:

* Reads `security.log`
* Counts failed logins
* Counts successful logins
* Prints a security summary

# 2. Create Monitoring Tools

A monitoring tool checks the current state of a system.

For example, we can monitor **CPU, memory, and disk usage**.

First install `psutil`:

```text
python -m pip install psutil
```

### Simple monitoring tool

```python
import psutil

cpu = psutil.cpu_percent()
memory = psutil.virtual_memory().percent
disk = psutil.disk_usage("C:\\").percent

print("SYSTEM MONITOR")
print("----------------")
print("CPU:", cpu, "%")
print("Memory:", memory, "%")
print("Disk:", disk, "%")

if cpu >= 80:
    print("ALERT: High CPU usage")

if memory >= 80:
    print("ALERT: High memory usage")

if disk >= 90:
    print("ALERT: High disk usage")
```

### Workflow

```text
Check System
     ↓
Read CPU/Memory/Disk
     ↓
Compare with limits
     ↓
Generate Alert
```

# 3. Develop Automation Workflows

A workflow connects several tasks together.

### Example

```text
Detect Event
     ↓
Analyze Event
     ↓
Create Ticket
     ↓
Send Notification
     ↓
Generate Report
```

### Simple Python example

```python
def detect_event():
    return {
        "type": "failed_login",
        "ip": "192.168.1.10",
        "count": 5
    }


def create_ticket(event):
    print("Ticket created for:", event["ip"])


def send_notification(event):
    print("Security alert:", event["ip"])


def generate_report(event):
    print("Security report generated")


event = detect_event()

if event["count"] >= 5:
    create_ticket(event)
    send_notification(event)
    generate_report(event)
```

### Main idea

Instead of doing every task manually, Python performs them **step by step automatically**.

# 4. Generate Security Reports

A security report summarizes what the automation found.

### Example

```python
ip = "192.168.1.10"
attempts = 5

with open("security_report.txt", "w") as file:
    file.write("SECURITY REPORT\n")
    file.write("----------------\n")
    file.write("IP: " + ip + "\n")
    file.write("Failed attempts: " + str(attempts) + "\n")

print("Report created")
```

The program creates:

```text
security_report.txt
```

Example content:

```text
SECURITY REPORT
----------------
IP: 192.168.1.10
Failed attempts: 5
```

### Reports can contain

* Date/time
* Event type
* IP address
* Number of events
* Severity
* Status
* Actions taken

# 5. Build Incident-Support Utilities

An incident-support utility helps security analysts investigate an event.

### Example: Failed-login incident

```python
incident = {
    "type": "Failed login",
    "ip": "192.168.1.10",
    "attempts": 7,
    "severity": "High",
    "status": "Open"
}

print("INCIDENT INFORMATION")
print("--------------------")
print("Type:", incident["type"])
print("IP:", incident["ip"])
print("Attempts:", incident["attempts"])
print("Severity:", incident["severity"])
print("Status:", incident["status"])
```

This doesn't automatically decide what to do. It simply provides useful information for investigation.
