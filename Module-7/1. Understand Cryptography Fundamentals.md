# 1. Understand Cryptography Fundamentals

Cryptography is a major part of cybersecurity. It helps protect information when it is **stored, processed, or transmitted**.

## 1.1 What Is Cryptography?

**Cryptography** is the practice of protecting information by transforming it into a form that unauthorized people cannot understand or use.

### Simple example

Original message:

```text
Hello Alice
```

After encryption:

```text
8fA#2kL9@xP...
```

Only someone with the correct **key** should be able to recover the original message.

### Basic process

```text
Plaintext
   ↓
Encryption + Key
   ↓
Ciphertext
   ↓
Decryption + Key
   ↓
Plaintext
```

### Important terms

| Term       | Meaning                                                        |
| ---------- | -------------------------------------------------------------- |
| Plaintext  | Original readable data                                         |
| Encryption | Converting plaintext into protected ciphertext                 |
| Ciphertext | Encrypted/unreadable data                                      |
| Decryption | Converting ciphertext back to plaintext                        |
| Key        | Secret or public information used by a cryptographic algorithm |
| Algorithm  | Mathematical procedure used for cryptographic operations       |

# 1.3 Confidentiality

**Confidentiality** means:

> Only authorized people or systems should be able to access the information.

### Example

Suppose you send:

```text
My password is ABC123
```

over a properly secured encrypted connection.

An attacker who intercepts the encrypted traffic should not be able to read the original message.

```text
Your message
     ↓
   Encrypt
     ↓
Encrypted data
     ↓
   Internet
     ↓
  Decrypt
     ↓
Original message
```

### Common technologies

* HTTPS/TLS
* Encrypted messaging
* Disk encryption
* Database encryption
* VPN encryption

### Simple Python example

Python can use cryptographic libraries to encrypt data, but cryptography should generally use **well-tested libraries rather than creating your own encryption algorithm**.

# 1.4 Integrity

**Integrity** means:

> Data should not be changed without authorization or detection.

### Example

Original file:

```text
security_report.txt
```

You calculate its SHA-256 hash:

```text
A1B2C3...
```

Later, you calculate the hash again.

If the file has changed:

```text
Original hash
     ↓
A1B2C3...

File modified
     ↓
New hash
     ↓
X9Y8Z7...
```

The different hash indicates that the file content changed.

### Python example

```python
import hashlib

with open("security_report.txt", "rb") as file:
    data = file.read()

hash_value = hashlib.sha256(data).hexdigest()

print("SHA-256:", hash_value)
```

### Important

A hash is **not encryption**.

```text
Encryption:
Plaintext → Ciphertext → Plaintext
                 ↑
              Can decrypt

Hashing:
Data → Hash
         ↑
   One-way operation
```

SHA-256 is useful for **integrity checking**, but it should not be treated as a password-storage solution.

# 1.5 Authentication

**Authentication** means:

> Verifying that a person, device, or system is really who or what it claims to be.

### Example

When you log into an account:

```text
Username
   +
Password
   ↓
Authentication
   ↓
Correct?
   ↓
Access granted
```

### Common authentication methods

**1. Something you know**

```text
Password
PIN
```

**2. Something you have**

```text
Phone
Security key
OTP device
```

**3. Something you are**

```text
Fingerprint
Face recognition
```

Using multiple categories is called **multi-factor authentication (MFA)**.

### Authentication vs Authorization

These are different:

| Term           | Question                            |
| -------------- | ----------------------------------- |
| Authentication | **Who are you?**                    |
| Authorization  | **What are you allowed to access?** |

Example:

```text
Login
 ↓
Authentication
 ↓
"User = Alice"
 ↓
Authorization
 ↓
"Can Alice access this file?"
```
