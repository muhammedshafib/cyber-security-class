# 🔐 TLS Handshake in Wireshark

## What is a TLS Handshake?

A **TLS handshake** is the process used to establish a secure connection between a client and a server.

### Basic Flow

```text
Client                         Server
  │                              │
  │──── Client Hello ──────────>│
  │<─── Server Hello ───────────│
  │<─── Certificate ────────────│
  │<─── Finished ───────────────│
  │──── Finished ──────────────>│
  │                              │
  │════ Encrypted Data ═════════│
```

## 🔎 How to Capture in Wireshark

1. Open **Wireshark**.
2. Select your active **Wi-Fi/Ethernet** interface.
3. Start capturing.
4. Open a new browser tab and visit an HTTPS website.
5. Stop the capture.
6. Use this filter:

```text
tls
```

## 🔍 Useful Filters

### Client Hello

```text
tls.handshake.type == 1
```

### Server Hello

```text
tls.handshake.type == 2
```

### Certificate

```text
tls.handshake.type == 11
```

### Finished

```text
tls.handshake.type == 20
```

## 📌 What to Look For

You can identify:

* **Client Hello** → Client starts TLS connection.
* **Server Hello** → Server selects TLS parameters.
* **Certificate** → Server provides its certificate.
* **Finished** → Handshake is completed.
* **Application Data** → Encrypted communication begins.

> **Note:** TLS 1.3 encrypts more of the handshake, so the packet sequence may look different from TLS 1.2.
