# 🔐 TLS Handshake in Wireshark

## What is a TLS Handshake?

A **TLS handshake** is the process used to establish a secure connection between a client and a server.

### Basic Flow

```text
Client                         Server
  │                              │
  │──── Client Hello ──────────>│
  │<─── Server Hello ───────────│
  │<─── Certificate ────────────│
  │<─── Finished ───────────────│
  │──── Finished ──────────────>│
  │                              │
  │════ Encrypted Data ═════════│
```

## 🔎 How to Capture in Wireshark

1. Open **Wireshark**.
2. Select your active **Wi-Fi/Ethernet** interface.
3. Start capturing.
4. Open a new browser tab and visit an HTTPS website.
5. Stop the capture.
6. Use this filter:

```text
tls
```

## 🔍 Useful Filters

### Client Hello

```text
tls.handshake.type == 1
```

### Server Hello

```text
tls.handshake.type == 2
```

### Certificate

```text
tls.handshake.type == 11
```

### Finished

```text
tls.handshake.type == 20
```

## 📌 What to Look For

You can identify:

* **Client Hello** → Client starts TLS connection.
* **Server Hello** → Server selects TLS parameters.
* **Certificate** → Server provides its certificate.
* **Finished** → Handshake is completed.
* **Application Data** → Encrypted communication begins.

> **Note:** TLS 1.3 encrypts more of the handshake, so the packet sequence may look different from TLS 1.2.

## 🎯 Simple Summary

```text
Client Hello
     ↓
Server Hello
     ↓
Certificate
     ↓
Finished
     ↓
🔐 Encrypted Application Data
```

# 2. 🔐 Investigate Certificates – Hands-on

## 🎯 Objective

Understand and investigate an **HTTPS/TLS certificate**, its details, and its **certificate chain**.

---

## 1. View Certificate in Chrome

Open:

```text
https://www.google.com
```

Then:

```text
🔒 Lock Icon
   ↓
Connection is secure
   ↓
Certificate is valid
```

A certificate window will open.

### Important Details

| Field          | Meaning                        |
| -------------- | ------------------------------ |
| **Subject**    | Website/domain                 |
| **Issuer**     | Certificate Authority (CA)     |
| **Valid From** | Start date                     |
| **Valid To**   | Expiration date                |
| **Public Key** | Website's public key           |
| **SAN**        | Domains covered by certificate |

---

## 2. Certificate Chain

Go to:

```text
Certificate → Certification Path
```

The chain usually looks like:

```text
Root CA
   ↓
Intermediate CA
   ↓
Website Certificate
   ↓
Website Domain
```

### Example

```text
Root CA
   ↓
Intermediate CA
   ↓
*.google.com
```

The browser verifies this chain to establish trust in the website certificate.

---

## 3. Investigate Using Kali Linux

### Connect to HTTPS server

```bash
openssl s_client -connect google.com:443 -servername google.com
```

### Show important certificate information

```bash
openssl s_client -connect google.com:443 -servername google.com </dev/null 2>/dev/null | openssl x509 -noout -subject -issuer -dates
```

Example:

```text
subject=CN=*.google.com
issuer=...
notBefore=...
notAfter=...
```

---

## 4. Investigate Certificate in Wireshark

Start Wireshark and capture HTTPS traffic.

Use:

```text
tls
```

To find certificate packets:

```text
tls.handshake.type == 11
```

Look for:

```text
Client Hello
Server Hello
Certificate
Certificate Verify
Finished
```

---

## 🧠 Key Point

A certificate helps the browser **verify the identity of a website**.

```text
Website
   ↓
Certificate
   ↓
Intermediate CA
   ↓
Root CA
   ↓
Browser Trust
```

### ✅ Hands-on Task Summary

* Check certificate details in the browser.
* Find the **Issuer** and **Validity**.
* Find the **Certification Path**.
* Understand the certificate chain.
* Use `openssl` to investigate certificates.
* Use Wireshark to find the TLS Certificate packet.

# 3. 🔐 Python Hashing Workflows

## 📌 What is Hashing?

Hashing converts data into a fixed-length **hash value**.

```text
Data → Hash Algorithm → Hash Value
```

Hashing is mainly used for **data integrity**.

---

## 1. Hash a String

```python
import hashlib

data = "Hello"

hash_value = hashlib.sha256(data.encode()).hexdigest()

print("Original:", data)
print("SHA-256:", hash_value)
```

### How it works

```text
"Hello"
   ↓
encode()
   ↓
SHA-256
   ↓
Hash Value
```

---

## 2. Hash a File

```python
import hashlib

with open("test.txt", "rb") as file:
    data = file.read()

hash_value = hashlib.sha256(data).hexdigest()

print("SHA-256:", hash_value)
```

`rb` = read the file as **binary data**.

---

## 3. Check File Integrity

```python
import hashlib

with open("test.txt", "rb") as file:
    data = file.read()

new_hash = hashlib.sha256(data).hexdigest()

old_hash = "paste_previous_hash_here"

if new_hash == old_hash:
    print("File is unchanged")
else:
    print("File has been modified")
```

### Workflow

```text
Create File
    ↓
Calculate Hash
    ↓
Save Hash
    ↓
Change File
    ↓
Calculate Hash Again
    ↓
Compare
    ↓
Same → Unchanged
Different → Modified
```

---

## 🧠 Key Points

* Python uses the built-in `hashlib` module.
* `sha256()` creates a SHA-256 hash.
* `encode()` converts text to bytes.
* `hexdigest()` gives a readable hash.
* Hashing is **one-way**.
* A small change in data normally produces a different hash.
* Hashes are useful for **file integrity verification**.
