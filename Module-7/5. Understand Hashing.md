# 5. Understand Hashing

Hashing is an important security concept used to **protect passwords, verify files, and detect data changes**.

---

## 1. Hash Functions

A **hash function** converts data into a fixed-length string called a **hash value** or **digest**.

Example:

```python
import hashlib

text = "Hello"

hash_value = hashlib.sha256(text.encode()).hexdigest()

print(hash_value)
```

Output will look like:

```text
185f8db32271fe25f561a6fc938b2e264306ec304eda518007d1764826381969
```

### Important points

* Same input → same hash
* Small input change → completely different hash
* Hashing is generally **one-way**
* Hash cannot normally be reversed to get the original data
* Different algorithms produce different hash sizes

Common algorithms:

| Algorithm | Use                                   |
| --------- | ------------------------------------- |
| MD5       | Old/insecure for security use         |
| SHA-1     | Old/insecure for collision resistance |
| SHA-256   | Commonly used                         |
| SHA-512   | Strong hash with larger output        |

---

## 2. Password Hashing

Websites should **not store passwords as plain text**.

Instead:

```text
Password
   ↓
Hashing
   ↓
Password Hash
   ↓
Database
```

For example:

```text
Password: MyPassword123
       ↓
Hash
       ↓
Stored hash
```

When the user logs in:

```text
Entered password
       ↓
Password-hashing algorithm
       ↓
Compare with stored password hash
```

### Important

For real password storage, don't simply use SHA-256.

Password-specific algorithms such as:

* Argon2
* bcrypt
* scrypt
* PBKDF2

are designed to make password guessing more expensive.

---

## 3. Data Integrity

**Data integrity** means making sure that data has **not been changed or corrupted**.

For example, imagine you download a file.

The original file has this hash:

```text
ABC123...
```

After downloading, you calculate the file's hash:

```text
ABC123...
```

The hashes match:

```text
Original hash == Downloaded hash
```

This provides evidence that the file contents are unchanged.

### Example

```text
Original file
     ↓
   SHA-256
     ↓
ABC123

Downloaded file
     ↓
   SHA-256
     ↓
ABC123

       ↓
   MATCH ✓
```

If the hashes are different, something about the file contents has changed.

---

## 4. Hash Verification

**Hash verification** means calculating a hash and comparing it with a known/expected hash.

Python example:

```python
import hashlib

text = "Hello"

hash_value = hashlib.sha256(text.encode()).hexdigest()

expected_hash = hashlib.sha256(b"Hello").hexdigest()

if hash_value == expected_hash:
    print("Data is verified")
else:
    print("Data has changed")
```

Output:

```text
Data is verified
```

### Security uses

Hash verification can help check:

* Downloaded files
* Software packages
* Important documents
* Backup files
* Security logs
* Data transfers

---

## 5. Collision Awareness

A **collision** happens when two different inputs produce the same hash.

```text
Input A ──→ Hash ABC123
Input B ──→ Hash ABC123
```

This is called a **hash collision**.

A good cryptographic hash function should make finding collisions extremely difficult.

### Example concept

```text
Data A → SHA-256 → Hash A

Data B → SHA-256 → Hash B
```

Normally:

```text
Hash A ≠ Hash B
```

But cryptographic security also considers how difficult it would be for an attacker to deliberately create two different inputs with the same hash.

### Why it matters

Older algorithms such as **MD5 and SHA-1** have known collision weaknesses, so they should not be relied on for modern cryptographic integrity or security purposes.
