# Step 3 — Create the backend

Create:

```text

```

Basic code:

```python
from flask import Flask, render_template, request

app = Flask(__name__)


@app.route("/")
def home():
    return render_template("index.html")


@app.route("/hello", methods=["POST"])
def hello():
    name = request.form["name"]

    return f"Hello, {name}!"


if __name__ == "__main__":
    app.run(debug=True)
```

Creates the function for the homepage.

# Step 8 — Security improvement

Our first version has a problem.

We directly use:

```python
name = request.form["name"]
```

We should validate the input.

For example:

```python
@app.route("/hello", methods=["POST"])
def hello():

    name = request.form.get("name", "").strip()

    if not name:
        return "Name is required", 400

    if len(name) > 50:
        return "Name is too long", 400

    return f"Hello, {name}!"
```

Now we have basic:

* Input validation
* Empty input checking
* Length checking

This connects directly to **Secure Development Principles**.

Then:

```text
User
 |
 | Login
 ↓

 ↓

 |

 |

       ↓

       ↓

```

### Important security rule

Never store:

```text
password = "mypassword123"
```

Instead store a **password hash**.

Example:

```text
Original password
       ↓
Password hashing
       ↓
$argon2id$...
```

The database stores the hash, not the original password.

## Workflow

```text

     ↓

     |
```

---

## Basic Python idea

```python
from collections import Counter

failed_ips = Counter()

with open("security.log", "r") as file:

    for line in file:

        if "LOGIN_FAILED" in line:

            parts = line.split()

            ip = parts[-1].replace("ip=", "")

            failed_ips[ip] += 1


for ip, count in failed_ips.items():

    if count >= 3:
        print(ip, "Suspicious:", count)
```

This gives you practical experience with:

* File handling
* Log parsing
* `Counter`
* Detection
* Security monitoring

# Example Security Finding

Suppose we find:

```python
query = "SELECT * FROM users WHERE username='" + username + "'"
```

We identify:

```text
Vulnerability:
SQL Injection
```

### Risk

An attacker may manipulate the SQL query.

### Problem

User input is directly joined with SQL.

### Better approach

Use a parameterized query:

```python
cursor.execute(
    "SELECT * FROM users WHERE username = ?",
    (username,)
)
```

### Result

```text
Unsafe SQL
    ↓
Identify vulnerability
    ↓
Understand risk
    ↓
Fix vulnerability
    ↓
Test again
```

Only test vulnerabilities against applications you own or are explicitly authorized to assess.
